# Learned versus supplied boundaries — DEV061.5, DEV062A and REAL-MAINT-001

| Surface | Learned | Supplied infrastructure or training assistance |
|---|---|---|
| Observation interface | Neural encoders consume public records | Typed vectors, sensor names, masks, public entity manifests and available choices |
| Identity | Shared recurrent content, soft CDL strengths | DEV061.5 hard cosine routing; DEV062A continuous cosine features to public manifest; no entity discovery |
| Relations | Neural relational computation and content; DEV062A encodes raw relation records recurrently | DEV061.5 additionally copies a gated public relationship-key stream; DEV062A has no such pointer-copy state |
| Memory | Recurrent content updates | Bounded64-record FIFO, no learned retention or C5 indexing |
| CDL/CASM | Soft relevance reads and trained dense neural operators/selectors | Fixed operator count and architecture; no symbolic program discovery or original CDL mechanism proof |
| Action consequences | Candidate-conditioned outcome/belief and cost heads | Synthetic laws and reference filter supply training targets outside deployment |
| Control | Trained policy scores select actions, correction and STOP | Externally supplied candidate vocabulary; generic numeric tie decoder, no repair/stop override |
| Uncertainty | Trained joint probability head and learned control | Four-state label vocabulary, known public sensor metadata and posterior-supervised StageA |
| Real observations | Next-sensor mean/variance networks trained without fault labels | Fifteen-source schema, causal ten-minute binning, four-hour input window and train-only scaling |
| Verification | Neural estimates are predictions | Independent execution/outcome checks; synthetic Veritas effects remain simulator-derived |
| Portability | Exported weights determine forecasts and policy scores | Torch-only eager CPU interface, float64, one thread, SHA256 integrity, schema checks |

DEV061.5 replaces the retired MTSK-superiority pursuit with shared GRU content
state, controlled identity treatments and twenty-seed training evaluation. It
remains a fully observable public-rule-solvable task. Its576 primary identity
rollouts per model reuse192 physical starts across three identity families.

DEV062A adds genuine ambiguous evidence and paid exact inspections, with explicit
public action-start provenance. Its256 primary rollouts per model reuse128 physical
starts across two noise-history lengths. A public history determines each exact
training posterior; privileged-action histories are not called exact public
posterior samples. This demonstrates posterior-supervised learning if it passes,
not discovery of the transition law without targets.

REAL-MAINT-001 is separate observational forecasting on one real compressor with
four reported fault intervals. It does not provide action-conditioned maintenance
counterfactuals or measured repair economics. Do not graft this encoder into the
control model and claim validated real-world planning without an integration study.

Twenty training seeds on shared held-out worlds measure optimization variability;
they are not twenty datasets, fleets or independent external replications. Model
restoration, native effect replay, cross-host matching, physical reliability,
architectural superiority and commercial viability are separate gates. Original
DEV058–061 weights, protocols and negative evidence remain unchanged.
