## Mandatory continuity rules

1. **No silent closure.** New ideas add a lane or a named successor; they do not
   erase the predecessor's blocker.
2. **No inheritance of invalid numbers.** An invalidated artifact may be used
   to explain a failure mode, never as a tuning target or scientific comparator.
3. **No inheritance of unverified positive interpretations.** A registration,
   smoke test, or workflow success is not a scientific result.
4. **Every current confirmatory run must pass G0-G10 and P0-P7.**
5. **Every lane has one next action.** When work is deferred, the blocker stays
   visible and the lane remains open.
6. **Promotion requires an artifact.** A claim cannot become SUPPORTED because
   its branch exists or its tests pass.
7. **Current-gate eligibility is separate from scientific validity.** Older
   valid results remain scientifically useful under their stated scope, but a
   new publication-quality claim must re-run under the current universal gates
   when that distinction matters.
8. **Agent continuity.** Before creating a new branch, an implementation agent
   must read this registry, the claims ledger, the evidence register, and the
   current blocker of the chosen lane. The branch must record its parent lane
   and successor relation.
