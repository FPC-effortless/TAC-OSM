## Scientific interpretation and next engineering gate

**A crucial negative:** adding an independent long-retention associative state solves the source scalar contraction of that particular state but **does not establish usefulness**, does not improve exact same genuine true carried-next-byte source score on any seed, and adds 256 FP32 bytes and compute. It should **not** be promoted, merged, or marketed as long-term factual memory. The original native fast memory remains more influential for next-token prediction under one-step old-matrix intervention. The dual slow lane's nonzero old state norm and stable rho do not demonstrate that useful historical content can be retrieved at delay64 or256.
