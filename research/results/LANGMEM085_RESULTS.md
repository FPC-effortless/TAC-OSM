## Registered bounded 8×8 associative bank, five operators and sources

All arms: original 8×8 FP32 bank **256 actual tensor bytes**, fixed injective normalized signed eight-bit byte code `c(byte)=(2bits−1)/sqrt(8)`, normalized SHA256(previous four **observed** byte context) writer key, original trained slow native source decay rho~0.989 from frozen 078, and identical observed source clock/current byte. No new trainable parameters, no model optimizer/gradient/head training or feature tuning. At current observed byte t, user-supplied old address for t-age and exact older source/key history kept by evaluator, **NOT** inside bank or original 4160B. Proposed original producer + candidate tensor bank **4160+256=4416 FP32 bytes** *if integrated*, excluding writer/clock/owner index, source cache and Python allocation. An actual fully integrated on-device decoder has NOT been benchmarked.

Five fixed prior-registered operators:
1. `source`: `rho M(I−beta kkᵀ)+epsilon vkᵀ`, original 078 learned source gates only.
2. `overwrite`: `rho M+(v−rho Mk)kᵀ`, unit rank-one delta; guarantees current-key write when k is normalized in exact real arithmetic (known delta-rule operator).
3. `partial025`: `rho M+.25(v−rho Mk)kᵀ`.
4. **`residual_clip035`**: `rho M+eta(v−rho Mk)kᵀ`, eta=`min(1,.35/(||v−rho Mk||+1e−9))`. A bounded per-write *residual-norm* step, not a learned semantic controller.
5. **`selective`**: same delta with eta=`1 if ||v−rho Mk||≤.75 else .25`. This gate uses only current observed source byte and old matrix, not an oracle old target/score. It is a deliberately prechosen threshold, not optimized.

Full delta and clipping have different multiply/compute/erasure gains than slow source, so **not matched-FLOPs architectural evidence**. No new theorem of neural identity encoding.

## Prospectively repaired negative control

Original 084 wrong-context control sometimes exposed historical byte label position a in decoy context `raw[b−4:b]` when `a<b≤a+4`. **085 excludes this BEFORE running ANY source**, rather than dropping outcome-selected rows later:
- For each candidate old event a and current observed source clock t, both hard and SHA-uniform wrong addresses are other already-observed writer clocks b with `4≤b<t`, `5≤|b−a|≤16`, and `raw[b−4:b]≠raw[a−4:a]`.
- Thus **no requested source position a appears inside wrong b’s preceding four source bytes**; both wrong candidates have close event ages within16 source positions and same source owner.
- Highest-key-cosine hard wrong and deterministic SHA-uniform wrong use same eligible pool and exactly the same original genuine source target as correct key. If no clean candidate the original job fails, never substitutes a different label/source/metric. All **4,780 original arm rows/model seed** have `decoy_clean=true` and exact age/owner/historical label SHA; strict aggregate verified all rows. Correct/hard/uniform predictions generated before the requested actual historical `raw[a]` is read by scorer, though the event byte is genuinely known to memory at write time.
- This does not eliminate every possible source correlation or equate wrong/correct key content geometry. Address remains evaluator supplied, no autonomous historical event search.

*The registered FIT modal-byte baseline at age256 happened to match **zero** genuine Rust targets (distribution shift or baseline insufficiency; do not treat it as evidence of long-history recall). The 256B raw ring has 240 data bytes and 16 cursor bytes; it returns exact retained bytes at ages8,32,128 when available and **unavailable** at age256. It is an exact short-range storage reference, NOT a standalone next-byte language model or autonomous memory index.*

At age8, residual clip correctly retrieves **36/256 actual source events** (14.0625%), versus hard wrong **14/256** (5.46875%) and original FIT prior **31/256** (12.109375%). All three original seeds use essentially the same deterministic bank encoding, so these **are not independent 3×256 evidence samples**. Compared with original source operator ~5.99%, clipped delta improves short-delay correct-address recovery by ~8.07 percentage points on this frozen two-document Rust cohort. But its gain over FIT prior is only **five source bytes**, and age32/128 accuracy remains below the FIT prior by wide margins. Residual clipping is more promising than the binary admission rule under these exact fixed conditions, but it is not a trained model capability win and not proven better under other sources/hyperparameters/budgets.
