## Measured conditions

Single GitHub Actions ubuntu-24.04 Azure x86-64 hosted CPU runner; PyTorch 2.10.0+cpu; Python 3.13, float32 eager, batch size 1, 2 intra-op CPU threads. Used the **original immutable trained seed-1701** checkpoints and complete SHA256 checks from the 320-update 5-seed LANGCOMPARE031 benchmark: TAC-CONTEXT026 (500122p), official pinned Pathway BDH (501504p), causal Transformer (496960p). The real input bytes came from authenticated original publisher FIT documents, no DEV or protected TEST. No new training, GPU, parameter changes or interpolation.

**Autoregressive decode** means 2 genuinely generated greedy bytes per repetition, repeated twice, recomputing the last at most 128 context bytes with each model's unchanged original inference function. This is not an incremental-state test, and none of the models uses a KV cache or persistent incremental state. Each model sees the same original input prompt, but generated bytes may differ.

## Major limitations

- **Short-form pilot only:** two actual generated bytes, two repetitions, one timed prefill sample. Do not report statistical significance or p95.
- Three earlier, longer attempts were forcibly stopped by GitHub hosted runner shutdown (not Python exceptions). They produced no valid latency receipts and are preserved as failed attempt history.
- Unlike hypothetical constant-cost incremental state, current CONTEXT026 is **window-reset and rejects a carried nonzero start position**; it performs a full prefix parallel scan every token. Transformer is also uncached, and BDH is the original unoptimized implementation. Measurements reflect current implementations, not architecture-optimal streaming latency.
- The P3 n-gram and fixed 75% P3/TAC hybrid speed was **NOT RUN** in the successful short-form test; constructing the full counts model was removed to isolate the three neural benchmarks.
- Shared-runner CPU variability, PyTorch kernel choices, lack of mobile hardware, lack of actual memory/power figures, and non-matched inference FLOP counts prevent generalized device efficiency claims.
- The earlier distinct authentic five-seed exposed-DEV predictive NLLs were TAC 2.099715, Transformer 2.559956, BDH 2.574637. The faster Transformer currently has poorer prediction quality than TAC in that earlier, already exposed narrow source evaluation.
