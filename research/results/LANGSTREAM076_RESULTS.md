## What was learned and what was NOT proved

**Supported within this limited genuine source diagnostic:** old native matrix contributes to next-byte scores at the immediate query boundary—when only that matrix is zeroed, NLL rises in all sizes. However, erasing the native state that existed at exactly clock128 had only a small aggregate effect on later source predictions after the same subsequent observations. This is consistent with **rapid overwrite/interference of that particular prior native state** or redundant preservation through other state channels; this experiment CANNOT identify the exact cause, or certify native memory lacks long-range retrieval. A proper write/read delay sweep with stable source-grounded historical keys, carefully bounded source availability and independent retrieval labels is still necessary.

The larger 12/16 native+aligned memory matrices **do not establish a language-quality improvement** on the same real carried context cohort: m8 has lowest average NLL; both bigger groups won only 1/3 pairs. The cost of FP32 persistent state grows from 3.9KiB? **No:** 3904 bytes (3.8125 KiB) to 4752 (4.640625 KiB) and 5728 (5.59375 KiB); **state size is constant in time**, but different per variant. Training and evaluation were not FLOP-matched across native dimensions, though trained learned params were within0.21%.

**Important scientific limits:** This is a narrow source-consistent no-fit diagnosis on *already exposed DEV* and a small 256-label cohort, not fresh held-out TEST or real-world autonomous decisions. Absolute positional feature policy `cap_all` was selected after earlier exposed DEV work; it is NOT a trained/independently tested new context solution. The one-step native zero suppresses prior native matrix but current write still occurs; the earlier wipe leaves aligned/wave/concept/upper channels with old information. No claimed direct far-history fact retrieval, multiowner adaptive learning, quality certification, device performance or independent benchmark competitiveness. True streaming source engine source-accurate numerical tests and snapshot guards do not prove complete IEEE/AD/Lean whole graph.
