## Mathematically comparable three complete models

Same 12 numeric features, constructed from real pre-action data: recency/12, log1p(history), mens,womens,newbie, 3 onehot zip categories, 3 onehot shopping channel categories, 1 fixed zero coordinate. No post-action outcomes/segment membership used as input. FIT-only standardization of numeric features except binary/categorical preserving scale stability. Same 3 typed goals {visit,conversion,log1p(spend)} and candidate 3 action logits Q(x,a,g). Only the **observed actual randomized action's** real outcome supervises each row; never hallucinate the other two potential outcomes. Each arm has trainable condition-specific 16D goal embedding and 96-width nonlinear action readout.

- action_tac: 12 sequential *feature coordinates* projected 1→16 then six fixed-paired native fast32/slow32 +8×8 associative delta-write steps (original TAC recurrence), state64. Feature coordinates are not time series; no persistent temporal cognition claim.
- action_gru: GRU1→57 over same 12 feature coordinates, state57.
- action_context: MLP12→125→64 non-recurrent.
These channel widths chosen before fits to match ACTIVE trainable parameter counts within 1% (assert actual integer counts, no dummy padding). All arms identical data, outcome loss, sample indices and 800 AdamW updates batch256 per seed. Fix two seeds 49001 and49002 (six total trained neural models). Require no optimizer/parameter-freeze mismatch. All models share exact goal/action output shape and supervised loss: BCEWithLogits(visit observed) +0.3*BCEWithLogits(conversion observed)+0.1*SmoothL1(log1p(actual_spend), model spend channel output). Test log1p(spend) alongside calibrated real visit predictions. No unverified dollar intervention costs.

## Registered real evaluation

Outcome metrics per heldout split: observed-action visit Brier/log loss, conversion Brier/log loss, log1p(spend) MAE. For actual action selection, visit-optimizing policy = argmax_a Q_visit(x,a) with no heldout threshold tuning. RCT offers exactly 3 known assignment propensities (1/3 each) by experiment design, validated observed frequency per FIT/DEV/TEST to confirm randomization balance; causal policy value under RCT consistency/ignorability assumptions estimated by inverse propensity and doubly robust (DR) using model predictions and observed outcome. Holdout policy comparisons include 3 constant arms and model-induced action, save observed effective sample sizes. Choose best fixed arm by actual FIT visit rate exclusively BEFORE heldout opened (likely Mens; no assumption), compare policy to that frozen reference. Bootstrap by original customer row (iid distinct customers) 400 resamples for paired DR differences, seed fixed; require lower 95% CI>0 for each native seed and visit Brier strictly below matched context & GRU in BOTH seeds before claiming capability superiority. Loss/gates frozen before fits. Difference vs fixed arm must survive confidence; else failed gate. No direct observed individual counterfactual; no persistent sequential feedback or System2 declaration. This is experimentally randomized policy value estimation, not live deployment.
