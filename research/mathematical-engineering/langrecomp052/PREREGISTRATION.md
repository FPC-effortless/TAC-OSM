# LANGRECOMP052 — original trained TAC deterministic full-prefix recomputation

**Prospective original-checkpoint CPU study, preregistered before numerical experiment.** Following LANGMEMORY051, a fundamentally different dimension of memory: source-key retention vs retained neural inference state/activation recomputation. GRAPH011 5.51MB-to0.0014MB and '99% VRAM' figures are user-provided prior claims and have NOT been source-authorized or independently reproduced here. This study does NOT implement the original GRAPH011 engine, and does NOT measure GPU VRAM or neural training activation rematerialization.

**Frozen actual checkpoint:** original LANGLAYER040 graph-free state48_no_graph seed1701 FIT320, model 499623 parameters; SHA256 `0cbc1b89f53ea2a0fe1371a179a9ff14cc35ae84d09f76bdab1dffeac4ac86cb`; source upstream CPython 3.13.0 at commit `60403a5409ff2c3f3b07dd2ca91a7a3e096839c7`. Reuse original model factory `model_for('h48_plain')`, actual `IncrementalTAC043('cap_all')`, full original optimizer/RNG/loaded state and original sample order SHA `45985ef86e7df644a3acfeee73fe781bbd8d2cb290ac6465dfe670579e6f702f`. Download original immutable checkpoint bundle from GitHub Actions 40797105091 with original artifact name `LANGLAYER040-CPU-state48_no_graph-seed1701`; validate every hash and provenance before execution. No retraining/weight edits. Genuine original PSF CPython FIT owner only, no DEV or protected TEST.

**Primary test**: prompt lengths128/512 actual publisher bytes, batch1, real original seed1701 model, growing prefix,16 deterministic greedy original next-token predictions. Compare conventional `IncrementalTAC043.step` retaining tensor state between inputs with `IncrementalTAC043.prefill` recomputed from **stored observed prefix bytes** at every additional generated token. Both policies are evaluated on EXACT same generated source prefix tokens from the original incremental baseline; no response-value differences or differing model samples. At all 16 continuation steps and prefill, compare FP32 last-byte logits with atol3e-5/rtol1e-4 and identical argmax; mismatches fail. Repeated source clock and state tensor schema verified.

**Benchmark** one Ubuntu GH CPU x86 runner with PyTorch2.10 CPU FP32 eager, 2 threads, batch1, 2 warmups+5 paired alternate-order timed repeats, original prompt 128/512,16 updates. Record raw time vectors, median/p95 decode, prefill, prefill+16, each repeated parity error, and genuinely persisted source-prefix bytes versus persisted floating tensor state. Model/setup overhead excluded from per-token timing. Emphasize model weights, activations/transients, Python/allocator heap, input tensor created during replay, and training gradients/optimizer are NOT included in retained-state byte counts. The original existing streamed model uses 3904 retained tensor bytes at batch1; recompute stores 128/512+16 byte original source prefix, but reconstructs massive transient states. Memory savings in this accounting cannot be extrapolated to *whole process* or *peak GPU VRAM*. Repeated full causal prefix may be much slower than incremental state.

**Falsifiers:** checkpoint/source/order identity change, state/schema mismatch, any per-step logits or generated argmax non-equivalence, source-owner crossing, any CPU timing/byte result without original trained checkpoint verification. Honest negative latency kept. The separate optimization of **training activation recomputation** requires genuine independent GPU measured peak torch.cuda.max_memory_allocated, same backward source loss/gradient/optimizer and a safe separately authorized dual-T4 run; it cannot be claimed from a CPU inference-only study. Original GRAPH011 implementation remains unverified, not silently imported.

**No neural improvement claim:** source-only inference efficiency/recomputation engineering, no trained new model, no protected TEST, no GPU, no model promotion, no new source heldout next-byte accuracy and PNDS complete source-typed math remains OPEN. The original 046–051 memory failure evidence is preserved. Study remains draft/unmerged.
