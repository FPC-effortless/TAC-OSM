# ME051 — Learn decision-relevant retention from authentic long rating histories

**Protocol frozen 2026-10-22 BEFORE any ME051 fitting or heldout labels read.** Parent: negative genuine KuaiRand chronological-memory trial ME050, draft PR316. Goal: improve TAC's ability to retain and use actual old observations, not merely increase recurrence length, use synthetic worlds, or optimize serving speed.

## Real dataset / source integrity
Original stable GroupLens **MovieLens 1M**: 1,000,209 human movie ratings, 6,040 anonymized users, real timestamps and 1–5 observed ratings; source `https://files.grouplens.org/datasets/movielens/ml-1m.zip`, immutable original publisher 2003 release. Require **publisher MD5 receipt** from `https://files.grouplens.org/datasets/movielens/ml-1m.zip.md5`, match actual downloaded zip (known historical MD5 c4d9eecfca2ab87c1945afe126590906) before parsing; save original ZIP SHA256 and decoded `ratings.dat` SHA256. Abort on corrupted header, unexpected record count, invalid IDs, missing ratings or timestamp failures. GroupLens research-only terms prohibit raw redistribution and commercial/revenue-bearing use without prior permission; do not publish archive, original individual sequences, demographic fields, or per-user predictions. Cite Harper & Konstan (2015) in publications.

Ratings are **actions voluntarily recorded by real users**, but not randomized recommendation interventions. This is numerical conditional preference/rating prediction, NOT causal action-conditioned control, inferred actual recommendation effectiveness or autonomous System 2.

## True per-user temporal boundaries and sealed future labels
First parse ONLY (user_id,movie_id,timestamp,source row index), NEVER rating, from the full publisher archive for ordering. Sort each user's records by (timestamp,original source row index). Set each user's fixed FIT[:floor(.70*n)], DEV[floor(.70*n):floor(.85*n)], TEST[floor(.85*n):]. Split membership uses retrospectively available sequence lengths and metadata; do **not** claim this is a future-calendar external prospective experiment. Train must parse only FIT rating fields on a second source pass. All model/checkpoint/optimizer RNG SHA hashes must freeze **before the first parsing of any DEV/TEST rating**. A third pass after freeze reveals DEV+TEST ratings. Test-time historical inputs may include **strictly earlier actually observed DEV/TEST ratings** under predeclared prequential evaluation. Equal-timestamp records cannot enter one another's history. Do not use demographics, later ratings, later movie outcomes, or user IDs as learned features.

A training/eval target must have at least H strictly earlier same-user real ratings (H in {16,64,256}). Last H real actions are encoded in their original chronological order; no fabricated padding is counted as observation. Aggregate 256 places into 32 chronological 8-event bins; mark empty bins as masked for H=16/64, with mask covariate. For H=256, all 256 records are real and historically prior. This **is** a 256-event input memory but only 32 recurrent state updates; no claim of retention across 256 separate dynamical update steps. For each H, evaluate the SAME fixed TEST target set containing >=256 true prior events so H comparisons use exactly the same users/labels. Choose up to 8,000 genuinely eligible TEST targets by deterministic index-based hash score, before opening any outcome labels. Report eligible users and counts; require >=500 distinct targets and >=20 users or abort. DEV period may be inspected only after checkpoint freeze and cannot trigger parameter or model selection.

## New predictive-retention math
Unchanged native TAC fast32/slow32+8x8 innovation step on 32 compact observed history tokens. Candidate movie's observed ID is supplied before predicting its logged rating. Add an **explicit auxiliary old-evidence retrieval head** to both native variants with identical trainable parameters; train one with weight λ=.20 and the other with λ=0. Old-evidence target is the *actual average rating of the earliest quarter of the supplied past H observed ratings*. It comes from genuine past labels already inside history, not fake events or future labels. The retained state predicts it after all 32 tokens. Per example:
`L = ((rating_hat - actual_rating)/2)^2 + λ*((old_mean_hat - past_old_mean)/2)^2`.
The auxiliary is a factual state-retention supervision signal; proving old information can be reconstructed is not, by itself, proving better intelligent decisions. To demonstrate useful intelligence, this auxiliary must also improve independent heldout **next real rating prediction**.

Two matched GRU controls (same 32 real token aggregates, same candidate context, retention-head inclusion, λ=.20 vs λ=0), plus a context-pooling control (λ=0) and train-only global-rating mean reference. **5 architectures × 2 seeds = 10 original real trained fits**. Matched seeds 51001/51002, identical original FIT index/length batch schedules by seed across all five models; 500 AdamW updates, batch64, lr.001, wd1e-4, grad clip1. H schedule cycles {16,64,256}, with each sampled target having at least H earlier genuine user events. Active trainable parameters recorded; near-compute/parameter matching is valid only **within native λ-pair and GRU λ-pair**, not across different architectures, and optimizer-CPU/FLOPs equality MUST be measured rather than claimed. CPU efficiency is secondary to intelligence.

## Preset scoring and decisions
Primary H256 heldout **rating MAE** (1-5 stars), secondary H256 RMSE and H16/H64 MAE on the **same original TEST target set**; old-evidence retrieval MAE for each H; user-cluster paired bootstrap 200 samples for native λ=.20 vs native λ=0 and native λ=.20 vs best external context/GRU. Additional ratings error by user-history-length quartile and 5-star-rate may be reported without tuning. No original test results viewed or used for refitting.

**Strict claim gate**: 2/2 seeds native retention must reduce H256 heldout MAE vs its exact native no-aux control; both user-cluster bootstrap 95% confidence intervals for paired improvement must exclude zero; native retention must also beat GRU+retention and context in H256 MAE in both seeds, with explicit cross-architecture parameter/CPU caveats. An auxiliary retrieval improvement **alone** is not a model-intelligence win. If any gate fails, preserve failure unchanged and do not promote. Outputs remain numerical ratings, not words, images, multimodal control, individualized causal potential outcomes or verified multi-step action planning.
