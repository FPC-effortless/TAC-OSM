## Original frozen ME069 TEST, **post-hoc**, 2,618 cases

| Reference / trained model | Next-event case-mean log loss ↓ | Next-event accuracy ↑ | Interpretation |
| --- | ---: | ---: | --- |
| FIT first-order transition (same empirical reference as ME069) | 0.348946 | 84.76% | Underspecified 1-step process reference |
| FIT second-order count model | 0.198247 | 92.25% | Fixed backoff, no neural model |
| FIT third-order count model | 0.172033 | 93.58% | Fixed backoff |
| FIT fifth-order count model | **0.159743** | **93.96%** | Best of four fixed practical references; ordering not tuned on TEST |
| ME069 trained native TAC (historical frozen) | 0.122626 | 94.77% | Shared FIT prior and neural learned event mixture |
| ME069 matched GRU (historical frozen) | **0.119182** | **94.77%** | Matched recurrent architecture, better probability quality |

The fifth-order original real-data reference reduces next-event log loss **about 54.2%** compared with the empirical first-order Markov reference and improves top-one accuracy about **9.2 percentage points**, with no neural memory. This is strong evidence that **limited factual context explains a substantial portion of the first-order-prior deficit**. ME069 TAC and GRU still score better than the fifth-order reference; that remaining gain may reflect richer observations, nonlinear state and/or their shared learned heads. **This does not attribute any improvement to TAC-specific associative memory.** The match with ME069's empirical prior to six decimals confirms the actual target and source alignment under this protocol.

DEV original scored diagnostic (1,850 cases): 1/2/3/5 order NLL = **0.303391 / 0.204608 / 0.168935 / 0.155936**; accuracy **85.30% / 90.32% / 92.86% / 93.46%**. All DEV and TEST numbers were generated by the published study's already known one-midpoint sampling method; the new n-gram's FIXED choices were neither optimized nor compared to select an architecture on those labels.

## Boundaries

- The n-gram parameters are *original trained FIT counts*, permanently preserved as model-state JSON and validated by a separate clean-clone restoration. This is a legitimate trained **non-neural practical reference**, not a parameter/FLOP-matched TAC head-to-head. It has 715 observed 5-step contexts rather than ~80k trainable neural weights and uses different numerical resources.
- A three-event, five-event or 32-event window cannot test native long-lifetime memory, and a process trace may contain easy lifecycle START→COMPLETE and SCHEDULE→START transitions. Later experiments must use only truly contemporaneously observable prefixes and separately score rare branching transitions.
- **Never promote the previously exposed BPI2012 TEST** as fresh evidence of TAC superiority. No new native TAC/GRU models trained; no >=256 event source qualified, no real action-value or production claim.
- BPI2018 official publisher [article 12688355](https://api.figshare.com/v2/articles/12688355) metadata were verified but original downloaded source bytes remained inaccessible on official Figshare routes (HTTP 504); the >=256 case cohort remains UNKNOWN and full ME070 paired memory trial BLOCKED.

**Next scientific action:** run the preregistered matched native/GRU/associative ablation only on an independently accessible verified real cohort with genuine 64+ (and independently 256+) histories, with full repository-backed original checkpoints and case-clustered inference. The existing authentic BPI2012 diagnostics are an important negative baseline correction, not that trial.
