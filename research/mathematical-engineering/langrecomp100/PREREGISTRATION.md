## Memory and time measurements

Each worker does two zero-update warmup F/B passes per data mode (four total); weights and optimizer moments must remain unchanged. Forward saved-tensor hooks on these representative original-parent FIT batches separately count logical requested bytes/events and distinct nonparameter requested storage identities. These are not physical peak memory or unique live activation peaks; logical totals may count aliases/parameter saves and storage identifiers may be reused. No held-out answer enters this phase.

All16 actual timed continuation steps run WITHOUT saved-tensor hooks. Record warmed forward, backward, clipping and optimizer arithmetic seconds separately; exclude source verification, gradient/weight/moment digesting, archive IO and cold-process imports from these component timings. Full worker elapsed time includes that overhead and is separately reported.12 language and4 episodic timings per policy/seed are small descriptive samples, not reliable deployment p95 estimates.

Physical memory: each policy is a separate fresh process with the original model, optimizer and gradients resident. On Linux reset only the current process VmHWM using /proc/self/clear_refs value5 immediately before each step, then record whole-process RSS high-water bytes after backward and after optimizer. Source byte data, weights/moments, gradients, runtime/workspace and allocator retention are included. Metadata hashing is zero-copy for contiguous tensors. Record baseline RSS and whether HWM reset succeeded; unsupported reset means physical within-step peak INCONCLUSIVE, never silently replaced by logical saved bytes. Process lifetime RSS is also retained. This is CPU RSS, NOT CUDA VRAM. Peak memory measured in this instrumented worker does not establish mobile/deployment cost.

Report each seed/domain and recompute/native median compute-time ratio plus maximum observed physical step peak and logical-forward save ratio. A useful CPU memory option requires exact correctness and lower272-slot physical peak in all three seeds; otherwise label mixed or no demonstrated physical benefit. Logical saves alone cannot pass that decision. No preregistered claim of99% total memory savings, no throughput/energy superiority and no precision change. If correctness fails, retain results, do not adopt or silently tune.
