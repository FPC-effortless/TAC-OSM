# LANGRECOMP100 mathematical execution contract

The original exact10M099 typed graph, parameter shapes, state dimensions, forward probability law, objective and all learned weights are unchanged. Inputs are observed Long[B,T] byte IDs, Bool[B,T] write entitlement, explicit owner tuple, nonnegative clock and original State099 floats: context376, lexical3×256, previous-key2×24, memory2×32×24,mass2×24. Outputs are logits Float[B,T,256] and the complete same-owner state at clock+T. FP32 only in real trial.

Let F_theta(x,s,m)=(logits,s_next). Native execution materializes the differentiation tape. Non-reentrant checkpoint execution returns the same F_theta, saves source inputs and recreates needed intermediate computations during reverse differentiation, preserving RNG. Parameters, inputs and buffers must remain unchanged between original forward and its backward replay. The100 wrapper passes masks and all floating state as explicit checkpoint arguments, so incoming-state derivatives are preserved; it captures immutable owner/clock metadata. No input float state is detached and no concept graph or architecture path is bypassed.

For deterministic step h_theta and prefix u/suffix v, fold(h_theta,s,u++v)=fold(h_theta,fold(h_theta,s,u),v). Re-evaluation from the same retained inputs reconstructs the same exact-real result. Extensional equality of parameter-to-loss functions implies equal Frechet derivatives wherever the original function is differentiable. This conditional statement does not prove source floating-point execution or actual automatic differentiation. Native099 exact-real persistent-state/bank/scan proofs are inherited unchanged. All full source graph equations are in the independent reference.py (same099 graph plus explicit deterministic replay); a PNDS replay/derivative module and numerical tests are linked separately.

Actual100 checks require identical entire gradient and optimizer byte streams over16 actual updates, not just final scalar losses. Optimizer/RNG dynamics are checked numerically from complete original archives. Neither exact-real replay identity nor logical saved-tensor reduction proves reduced physical memory: source bytes, weights, Adam moments, gradients, temporary recomputation workspaces, allocator behavior and CPU/GPU runtime must remain accounted. Checkpointing may perform extra computation and may increase backward peak. No full IEEE/AD proof, universal Williams theorem, globally optimal checkpoint placement or intelligence gain is claimed.
