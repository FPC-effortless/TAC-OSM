# Draft: direct-evidence execution and episodic acquisition assay

**NOT REGISTERED. NOT ENABLED. NO FIT OR EVALUATION AUTHORIZATION.**

This is a proposed separate experiment, written before LANGCONTROL098 outcomes.
It changes none of that study's frozen source, training, cohorts, evaluator,
decision rules or endpoints. A future run needs its own reviewed registration,
phone plan, source/data seals, parameter/resource gates and mathematical record.
No optimizer steps or model calls were performed for this proposal.

## Question and evidence boundary

The parent097 outputs fail both serialization and content. A useful diagnostic
dependency is whether the same compact models can first execute a simple known
transformation and emit a complete grid, before interpreting an unknown-rule
transfer failure. This assay deliberately narrows the task; success would not
retroactively turn original097 or098 ARC failures into successes.

Use licensed original ARC **input grids**, split by original source-task owner,
as observed geometry/content. The proposed target transformations and mapping
facts below are constructed. The result must therefore be labeled a
**constructed capability diagnostic derived from real input grids**, not
performance on original ARC solutions, natural operational outcomes, or general
intelligence. Record source revision/license and original input hashes. Never
use official query outputs to construct an actor's observations.

## Retain the exact compact byte interface

The existing encoder represents a grid as its two ASCII dimension characters
(each1..6) followed by row-major color digits0..9. A demonstration is
`encoded_input>encoded_output;`. Acquisition begins with `R;`, query is
`encoded_query_input>`, and the model must generate `encoded_answer;`.

For a pointwise mapping `f`, supply ten elementary mapping facts in acquisition:

```text
R;11c>11f(c); ... one pair for each color c from0 through9 ...
```

The notation `f(c)` above is explanatory; actual inputs contain only the
existing dimension/color digits and `R;`, `>`, `;` delimiters. Each pair is8
bytes; acquisition is82 bytes. A6×6 query including `>` is39 bytes and its
answer including `;` is39 bytes, so `A+Q+Y<=160`, within the existing272-byte
training geometry and192-byte acquisition limit. There is no new opcode,
target-length feature, oracle answer grid or solver output in the model input.

Keep the256-byte output alphabet, greedy40-byte generation allowance, and strict
first-semicolon grid parser. Neither gold dimensions nor gold stopping positions
may constrain decoding. Any future constrained-decoding arm would be a separate
registered interface intervention.

## Stage A: execute an already known nonidentity operation

Use a fixed rule, for example `f(c)=9-c`, for every episode. It changes every
integer color, so copying the query unchanged cannot solve it. The elementary
facts give the complete transformation, but never present the completed query
output. Test grids have unseen arrangements and source-task owners. The model
must produce the transformed cells, the two dimensions and the correct stopping
delimiter while generating its own previous bytes.

This measures learned execution and serialization for this restricted operation.
Because the operation is fixed across training, it may become parameter
knowledge; ignoring the redundant fact block would not invalidate Stage A and
would not establish acquisition. Passing would not prove that the model can
execute all heterogeneous original ARC transformations.

The external evaluator independently computes the pointwise transformation on
the observed input. Its implementation and gold outputs remain outside the
prediction actor. An executable oracle is an evaluator/solvability check, not a
trained-model score. Include unchanged-query copying and constant-grid baselines.

Report free-running exact-grid success as the primary endpoint. Report format
validity, height/width accuracy, first-delimiter position, predicted payload
length and cell accuracy conditional on correct dimensions as diagnostic
components with explicit denominators. Invalid outputs stay failures of the
primary endpoint; do not select a favorable subset or repair their strings.
Training loss or teacher-forced accuracy cannot substitute for free generation.

A future registration should set a demanding absolute execution threshold and
per-seed floor before opening confirmatory data, using a development-only pilot
and an adequately sized task-owner cohort. The draft does not select a threshold
after seeing098 or new assay results.

## Stage B: acquire episode-specific facts, then retain and deploy them

Replace the globally fixed mapping with an independently sampled color
permutation for each episode. Freeze training/development/confirmatory mapping
and source-task identities before fitting. Hold out mapping combinations as well
as source owners; audit duplicate grids, duplicate permutations and overlapping
support/query records. Randomization and its seeds must be independent of model
outcomes. Balance mappings so no query-only fixed color preference supplies the
answer.

Begin with all ten elementary facts. Every queried color is then identifiable;
the actor receives information sufficient to compute the result, rather than an
underdetermined sparse-support task. Only after this condition works should a
separately frozen support-budget curve reduce facts or use multicell examples.
For reduced support, prove that every scored query-color assignment is
identifiable under the declared mapping class; otherwise report ambiguity and
the attainable information bound instead of labeling an impossible case failure.

Separate existing competence from acquisition by comparing performance before
the episode's facts with performance after them on new grid arrangements. Then
deliver acquisition first, withhold its bytes from the later query actor, and
test retained state, complete reset, source-compatible donor facts, and a
naturally no-evidence condition. Include sham interventions and audit all
alternative information paths. Reset or donor effects alone are not a universal
claim about memory; some facts are necessary by this task's construction.

Preserve all cases and seeds, complete checkpoints/optimizer/RNG, acquisition and
query byte hashes, original states, generated bytes and fresh-process replays.
Charge acquisition, storage, querying, generation and training separately. Match
original active parameters and training/data/tuning budgets before comparing
model families; unchanged wall-clock time is not a fairness requirement.

Stage B can establish acquisition, retention and deployment of new **mapping
information** and transfer to new arrangements. It does not establish invention
of a new algorithm, discovery of an unrestricted hidden program, or a general
theory of intelligence. Those are distinct later hypotheses.
