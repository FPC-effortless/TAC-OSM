# Frozen ME100 protocol

The accompanying FAIR_COMPARISON.json is the machine-readable prefit registration. One trial, five seeds, 1,536 updates, batch16, context8/64/256 in fixed rotation, AdamW .0006, weight decay .001, gradient norm1. Objective: masked proper censored-lognormal NLL plus .1 standardized-log mean-square loss. Each batch samples8 FIT natural-gap queries and8 general FIT queries with replacement. Oversampling gaps is deliberate; the reporting distributions remain separate. 24,576 origin exposures and 2,686,976 history-event exposures per model are presentations, not independent records. Six pollutant labels are supervised where actually observed.

No REPORT metrics during training. All original model, optimizer, RNG, sample schedule, FIT preprocessing, source code hashes and live parameter receipts must be committed before scoring REPORT. The scoring script hard-checks Git bytes before opening REPORT. Training output paths cannot be overwritten or silently resumed. All five original checkpoints are retained regardless of result. CI replays originals and never trains.

Every seed must achieve primary PM2.5 MAE at least5% below its recent8 access condition, at least3% below the stronger of LOCF and fixed FIT-ridge refs, general PM2.5 MAE no worse than1.05LOCF, and primary nominal90% interval coverage at least85%. This is a bounded development capability gate; it is not an architecture-comparison or independent deployment gate. Failure ends this registered run, without changing gates or fitting more seeds against REPORT.

Report all six pollutant MAEs, proper density NLL, coverage and interval scores. Bootstrap2,000 global calendar-week paired samples across all stations; report conditional five-fitted-model uncertainty, no retraining uncertainty or multiplicity-controlled superiority claim. Report actual sample/cluster counts even if scarce. The 2016–2017 numerical cohort remains closed for later independently registered matched qualification. The source loader reads calendar year to stop before converting protected numerical values.
