## Question and limits of083

083 showed that one trained readout did not establish address-specific
recall. It did not rule out every decoder, larger memory, forgetting policy
or compressed recall architecture. The actual native source already has
separate native_key and native_value projections. Here explicit byte identity
is tested against its learned byte+position value representation; do not
claim that separate key/value projections are newly invented.

A four-byte-context address also cannot distinguish two occurrences of the
same context having different continuation bytes. This is not necessarily
erasure: **unique context**, repeated same-byte context, and repeated
conflicting-byte context must be counted, with exact valid denominators.

## Fixed eight-arm component factorial

All use8×8 FP32 matrices, zero start at each source owner. All source clocks
and values are causally observed before a write. Each arm consumes the same
source byte stream and source-trained gate constants; no label-driven arm,
query, key or update selection.

1. Value: original frozen native_value(embedded byte+source time), or
   c(byte)[i]=(2 bit_i(byte)-1)/sqrt(8). The latter is an injective fixed
   eight-dimensional byte code, no learned weights and no decoder fit.
2. Writer address: original frozen key from the preceding four observed
   bytes, or normalized SHA256(`LANGMEM084-key-v1`+NUL+preceding4bytes),
   eight little-endian uint32 values mapped to(-1,1). Left-zero padding only
   before four bytes exist; historical primary anchors always a>=4. No age,
   event index, current written byte, future byte or owner ID in the hash.
   Equal contexts intentionally have equal addresses; SHA output is not a
   semantic learned encoder and is a diagnostic control only.
3. Update: original M'=rho M(I-beta kk^T)+epsilon vk^T, source gates
   unchanged; or **fixed unit residual overwrite** M'=rho M+(v-rho Mk)k^T.
   Both updates use the same rho. Unit overwrite changes erase/write gain
   and operation count, not only one coefficient. This is an established
   delta-memory mechanism, not a novel TAC algorithm or equal-FLOP comparison.

Prior art reused: associative outer-product memory (Kohonen1972), fast weights
(Schmidhuber1992), delta-rule linear attention/DeltaNet (NeurIPS2024). A
factorial fixed control is not evidence of superiority to their trained models.

## Falsifiers and acceptance

- Explicit values improve correct-versus-both-wrong recovery with native
  keys/source update: value representation is implicated under these controls.
- Hash contexts improve discrimination holding value/update fixed: native key
  geometry is implicated; repeated-context aliasing remains possible.
- Unit overwrite improves short ages but harms long ages: recency/interference
  tradeoff, not global content-recovery success.
- No arm separates correct from uniform wrong on unique-context rows: these
  eight-dimensional reads remain inadequate under the fixed decoder.
