For each query, register **all 9** (L,H) combinations:
- Context lengths L = **2,3,4** observed source bytes; original causal query `raw[t-L+1:t+1]`, candidate source preceding write context `raw[a-L:a]`. Exact equality labels a source-context positive. This is **not proof that a learned model should always repeat the old continuation**, and a repeated phrase can have different next bytes.
- History age caps H = **32,128,256**; candidate historical writes `4≤a<t` and `1≤t-a≤H` from the **same source owner**. This is an off-model bounded side-table diagnostic; it does NOT live within TAC's 4160-byte persistent native state.
- A frozen trained-original-source **learned native query** q_t ranks old writer keys `w_{a-1}` by normalized dot similarity over all candidate writers. Score top1 historical *context* match, best-positive reciprocal rank (conditional on at least one source-positive), and top1 historical continuation raw[a] next-byte accuracy. Do not cheat by ranking on raw[t+1] or using future next-byte to select candidates.
- **Exact-history control**: most recent a among context-positive matches; its actual previously observed raw[a] is a known historical next-byte suggestion. Also count all matching source continuation bytes and output frozen Bayesian smoothed probability `p(y|context,history)=(c_y+8/256)/(N+8)`; original true y is only accessed in the *scoring stage*. Exact string matching is allowable source-history side-table computation, **not a trained neural retrieval achievement** and not a future-label oracle.
