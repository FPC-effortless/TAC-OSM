# LANGMEM083 — original frozen native state, learned 9120p readout and new unseen publisher DEV

This study and both new genuine publisher document SHA256 were frozen **before** any probe training or new DEV measurement. Purpose: determine if a fitted small decoder can recover an old observed byte from the existing actual compressed slow 8×8 source memory better than an equally trained address-only and wrong-address decoder, contrary to the original fixed untrained inverse codebook failure in LANGMEM082.

Original encoder is the immutable 499627p 078 source-trained dual TAC, 4160B FP32 original recurrent native state. **No gradients or optimizer updates to the original encoder/slow state.** Historical address `w_{a-1}` from the original source model is STILL evaluator supplied. This is a *capacity/decodability probe*, not autonomous retrieval and does not qualify a deployed TAC architecture. New learned head 20->32 ReLU->256 is exactly (20×32+32)+(32×256+256)=**9120** active learned parameters; original deployed frozen base+head=**508747**, additional ~36,480B FP32 weights, not counted in original 4160B persistent state. This is narrowly registered as **auxiliary probe math**, NOT a general waiver to the lab 100K model budget or a claim of a new 500K architecture winner.
