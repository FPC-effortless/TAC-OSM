## Single preregistered primary estimand on user5

For event i with real observed y_i, model m and seed k, let e_{m,T,k,i}=(p_{m,T,k,i}-y_i)^2. Define event-specific interaction:

D_{i,k} = (e_{TAC,128,k,i}-e_{TAC,32,k,i})
        - (e_{GRUoriginal,128,k,i}-e_{GRUoriginal,32,k,i}).

Primary point estimate: mean_i mean_k D_{i,k}, with all three fixed seeds, **not** pretending seeds are independent replicates. Primary 95% CI: paired bootstrap resampling **user ID** clusters with replacement at least 2000 times, recomputing a single pooled event-weighted all-seed mean of D using the same user draw across all models, lengths and seeds. Report per-seed interactions and between-seed range as robustness; user counts, target rows, original boot seed 21021; user-level cluster bootstrap alone cannot absorb seed-training stochasticity. Positive interaction = TAC's longer history performs relatively worse; if CI includes 0, report inconclusive. This is a descriptive architecture comparison, NOT a fully fair training compute comparison because original ME019 FLOPs/CPU training budgets differed. No selective positive result promotion.

## Interpretation gate

A narrow confidence interval excluding zero can establish this specific unseen-user **observational interaction**, not its memory mechanism or universal architectural superiority. If calibration removes most of the descriptive TAC128 Brier deficit, prioritize recalibration and optimization before architectural memory changes. If simple EWMAs or logistic/MLP beat every trained recurrent arm, model capacity is not justified yet. If the old96 summary improves beyond recent32 but strong baselines capture that gain, look at readout/objective, not exotic state storage. Only after these checks propose ME022 and a genuinely matched compute experiment.

Retain native TAC original 32 checkpoint and ME018 optional verified native execution optimization. ME019, ME019F and ME020 remain draft and unmerged; do not merge/promote a new architecture on these diagnostic results.
