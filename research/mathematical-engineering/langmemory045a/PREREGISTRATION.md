# LANGMEMORY045A — causal source-only complementarity preflight

**Prospectively registered, 29 October 2026, before executing any authentic publisher-source diagnostic.** Related target issue #574 and previous LANGSTREAM043 source-scope failures; this is **not** a new trained neural model or a verification of long-term TAC intelligence.

### Bounded hypothesis and inputs

Test whether two *cheap representations with different failure modes* and a selectively called expensive exact comparator are even mechanically complementary on authentic observed source histories. Use original source-verified genuine publisher PSF CPython FIT documents (14 source owners), never DEV or protected TEST. Process independent owners separately, each original document's first at most 1,536 byte events. Every prediction at t receives only original bytes x[0:t], no observed byte x[t] or later; query context = actual previous 3 bytes, evaluated every fourth step starting t=128. All prior counts and candidate values are original earlier next-byte observations, never fabricated target labels. Use one fixed algorithm, no trial selection, gradients or tuning.

- **A, high-resolution recent:** exact equal-context observed continuations within prior 64 positions, majority vote; absent if no matches. 64 byte ring lower bound.
- **B, stable bounded approximate:** 256 deterministic FNV hashed context buckets with Boyer–Moore candidate/vote/total, updated after each observation; fixed nominal compact representation 5 bytes/bucket =1,280 bytes; collisions and candidate cancellation expected.
- **V, slow exact:** scan earlier genuine same-owner source instances of that 3-byte key, return majority of their strictly earlier byte continuations; exact prior-prefix reads cost O(t) and retain up to t input bytes. This is not free memory.
- **Deterministic budget gate:** at 1 in 5 sampled positions only, if A or B is missing or predictions disagree. V is applied if a genuine earlier source occurrence exists; otherwise fall back to cheap fusion (prefer A when available, else B). No current/future target, oracle correctness, loss or DEV label influences the decision.

### Falsifiers and comparisons

Five arms (A, B, cheap A/B, budgeted V, full expensive V) evaluated on identical genuine prior histories. Report total events, coverage (fraction of events with a prediction), accuracy conditional on coverage, long-history recoverable positions, long-case accuracy and coverage, trigger fraction and full source positions scanned, observed bucket collision count, source/check identities. **Do not report a neural NLL, invented baseline or streaming TAC quality improvement:** these candidates are not yet normalized learned probabilistic models, and source memory is only a diagnostic. A source retrieval failure or no complementarity blocks further learned-memory work; gains on source probes are necessary but insufficient.

### Scientific boundaries

The diagnostic retains the full genuine source prefix for V, while A+B have only a nominal packed memory representation; actual Python heap and runtime storage not counted by that compact estimate. The diagnostic collision-key sets are **analysis-only**, not part of the cheap runtime. No copied foreign-owner histories, later timestamps, synthetic records as evidence, checkpoint use, GPU, TEST, optimization or novel model promotion.

After this step, design reciprocal PNDS Lean+Python for actual neural A/B/V computation, establish candidate retrieval false-positive controls and correct earlier-record interventions, compare real source NLL and quality/latency/memory frontier, and only then consider five-seed matched 500K training with fresh untouched documents. All improvement claims remain OPEN.
