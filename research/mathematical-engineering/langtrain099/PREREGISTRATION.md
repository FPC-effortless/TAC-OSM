# LANGTRAIN099: trained exact 10M contextual associative TAC

Registered before any optimizer update or DEV model prediction. The owner requested a trained 10,000,000-parameter model. This is a fixed-recipe, single-model internal FIT/DEV pilot, not a matched neural architecture comparison or complete language pretraining.

## Questions and decision rules

1. Does training improve held-out next-byte language NLL compared with the exact same original initialization? Primary language estimand: mean initial-minus-trained NLL on 176 fixed 256-target windows, reported separately for original code and documentation prose containing code examples. Positive improvement requires a publisher/file-cluster bootstrap 95% interval above zero and improvement in all three seeds. Report FIT-only smoothed bigram NLL as an unmatched reference.
2. Does acquired state enable exact lexical reuse? Report exact four-byte completion, first-byte NLL/Brier/confidence and 1–4-byte prefix accuracy separately for the two registered lexical groups. A useful-memory result requires nonzero exact carried completions in every seed and carry-minus-reset and carry-minus-donor exact accuracy bootstrap intervals above zero. Otherwise FAIL; missing controls are INCONCLUSIVE. Correctness alone does not establish novelty or persistence.
3. Does acquired state enable held-out ARC rule transfer? Report valid-format rate and exact grid accuracy for all eight authored ARC tasks. A supported diagnostic requires nonzero exact carried solutions in every seed and positive paired carry-minus-reset and carry-minus-binding-shuffle intervals. Missing controls remain INCONCLUSIVE. This is a narrow abstraction/composition diagnostic, not a test that can establish general intelligence.

No combined intelligence score; preserve every outcome. Reset/donor/corruption apply to ALL floating persistent state, with stream clock preserved. Five ARC donors are unavailable and must not be silently counted as successful controls. Compare available subsets explicitly. Bootstrap seed-averaged paired case effects using 5,000 resamples of original code-source or ARC-task clusters; three seeds and small task counts limit inference. Both case-weighted and equal-cluster means are reported; intervals refer to the latter.

## Fixed model and optimization

Exactly 10,000,000 active trainable/deployed learned parameters: embedding 256, context 376, two banks with 24 addresses and 32 values each, gated feed-forward width 4335. No padding weights, pretrained weights, graph expansion or frozen learned encoder. FP32 only. Three fixed seeds 9901, 9902, 9903, shared source and recipe, no tuning or best-checkpoint selection.

Each seed receives 2,048 AdamW updates, batch four. Three of four updates train full next-byte prediction on independently reset 128-byte source windows. Every fourth trains two lexical and two ARC FIT episodes with 272 padded slots per example. The episodic objective gives equal weight to each domain and each case's mean future-answer CE, plus 0.5 times each case's mean valid prefix CE. Prefix coefficient does not change future-answer coefficients. LM and episodic updates are distinct steps; report their losses separately. AdamW lr 0.0003, 64-step warmup then cosine to 0.1 ratio, betas (0.9,0.999), epsilon 1e-8, weight decay 0.01, global gradient clip 1, two CPU threads, no mixed precision. No hidden-state detachment inside an episode; state resets between examples/batches.

Training contains 786,432 real language targets per seed plus the actual episodic targets recorded in each original journal; padded slots are reported separately. The corpus has 3,219,298 bytes, so this is a bounded pilot and does not exhaust even one language-corpus epoch. A weak or negative result cannot settle architecture scaling capability.

Before any optimizer step, archive three original initialized state_dicts and zero-update source-authenticated FIT forward/backward profiles. Fix the exact profile artifact/run and successful scaled PNDS proof source before enabling training. Profiles do not fit parameters or inspect DEV outputs. The per-seed training deadline is 2,220 seconds; the profile estimate includes 75% overhead and 120 seconds. If estimated runtime exceeds budget, any change must be registered before all first optimizer steps, preserving old records and initializations. No automatic retries of partial fits or silently changed schedules. Planned maximum experiment CPU runner minutes: 15 readiness + 3×37 fit + 30 evaluation = 156, excluding package setup. No GPU allocation.

## Data, causal boundaries and leakage threats

FROZEN_INPUTS.json pins all source/data manifests. 197 authenticated licensed original FIT code/documentation files from nine publishers; 22 complete held-out language files (four code and 18 documentation) never enter neural training. The broader pilot originally included the four old lexical DEV source files; these are now removed in their entirety before sampling. Original 128 lexical/24 ARC FIT and 64 lexical/eight ARC DEV episodes are reused without altering targets. Separate FIT and EVAL artifacts; fit jobs receive only FIT. All three final checkpoints, optimizer steps/moments, sample journals and cold FIT replays seal before ANY neural DEV inference. No protected TEST access.

DEV is public and previously exposed during LANGACQUIRE097 development. It is not independently blind. Lexical group names are inherited from the earlier restricted FIT source list; names may occur elsewhere in broader FIT, so group membership does not establish vocabulary novelty. Source-file exclusion does not establish semantic deduplication. ARC tasks are human-authored secondary diagnostics. The same fixed byte output vocabulary applies to all models, with no target-derived candidate lists or output constraints. Greedy lexical generation is exactly four bytes; ARC is exactly 40 bytes then independently decoded. No judge-derived stopping or target-length feedback.

Prediction actors receive earlier acquisition bytes and then query bytes in separate processes. Opaque case IDs are state-ownership metadata only and never model inputs. Saved state is the only carried information across the boundary. Donors are selected from past observations without target access. Query actors cannot read target/judge arguments; original/replay outputs and states must agree and remain unchanged. Source files and evaluator share repository trust: this is an internal procedural boundary, not independent writer-ACL or reward-integrity certification. Missing formal AD/IEEE proof or unattested external boundaries remain OPEN.
