## New positive scale and valid predictive measure

For each channel, m=1 when the current observation is missing:

    b = sqrt(1e-6 + future_variance + response²*current_variance*m)
    w_left/right = exp(log(4)*tanh(raw_width_left/right))
    sigma_left/right = b*w_left/right

All component variances and w are positive in exact reals; w lies strictly between1/4and4. No empirical age-difference floor or max(.8b,...) is applied to the new forecast. This deliberately changes initial interval predictions, while raw medians and every native tensor state are bitwise preserved when loading the ME110 parent. Initial contraction is recorded, not called learned improvement.

The reported law is generated by U~N(0,1), Z=location+sigma_left*U if U<0 and location+sigma_right*U otherwise; Y=max(0,expm1(target_mean+target_scale*Z)). Each half retains probability1/2, giving a valid median-preserving distribution with a censored atom at0. Positive densities use the log1p Jacobian; zero outcomes use the atom's logCDF. This law is normalized although asymmetric densities can jump at the median. Its pre-censor variance is (sigma_left²+sigma_right²)/2-(sigma_right-sigma_left)²/(2pi), not b². The component sum is a conditional base-scale design, not an identified physical decomposition or exact full-network law-of-total-variance theorem. No guaranteed gap coverage, finite expm1 output under arbitrary weights, or finite-sample statistical safety theorem follows.
