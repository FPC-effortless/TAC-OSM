## Research question and inherited architecture

Does an explicit reversible continuous-flow / discrete-event wrapper and token-context metric change **actual original TAC** predictions as implemented, while preserving source isolation, bounded flow and testable negative controls? **This alone is NOT evidence of useful semantics, adaptation, continuous-time capability or architecture superiority.** Source core is `research/mathematical-engineering/langmem086/compact_tac.py`: original 100,521p byte model with fast8x8, slow8x8, aligned2x8x8, wave4x2, concept4x8, basis48, lexical3x32 and upper32 states (1,920 float-state bytes / owner). Frozen core remains identical. Added sidecar floats: elapsed-time and mode, not counted in the original fixed-size tensor state.

**Specified hybrid sidecar** for *upper state only*: `dx/dt = -lambda_q*x + w`; exact closed-form integration for constant w, `lambda0=.015`, `lambda1=.15`, default `w=0`; event rule LF byte10→mode1, period46→mode0, otherwise retain mode, applied only when current observed byte arrives. On mode transition only, reset upper by `r0=1`, `r1=.9`. Nonexpansive resets. Then call the **original** byte update/decoder. Null intervention rates0/resets1 MUST reproduce original logits/state bitwise. Observed byte ordinal used as diagnostic clock, **not physical elapsed interaction time**. Enforce monotonic positive minimum dwell after first event (1e-6), finite tensor/time, entity identity, and no future byte visibility. This wrapper does not prove boundedness of the complete trained TAC recurrence after neural writes.

**Semantic conditions:** fixed Euclidean original token table; contextual Euclidean `z_a=E[a]+.15<E[a],u>u`, `u=normalize(upper)`; and rank-one SPD metric `G=I+.5 u u^T` on contextual embeddings. Frozen correction to candidate logit is `-.01*(d² - mean_vocab(d²))` relative to the *current observed token*; no target token or future information. Also test hybrid plus contextual SPD. **No geometry parameters are trained**. The spatially varying optional `G(z,c)` is only evaluated as a positive-definite metric and straight-line path-length **upper bound**, not an optimized geodesic. Matching Euclidean vs SPD is an operator ablation, not a compute-matched newly trained architecture comparison.

**Stability:** for `V=||x||²/2`, with lambda>0, `dot V <= -lambda V + ||w||²/(2lambda)` and for mode-reset `V(x+)<=V(x-)` by `r<=1`. Finite minimum event dwell prevents constructed Zeno schedules. Float64 analytic fixture semigroup/finite perturbation checks test these narrow guarantees. `lambda=0` used solely as null-treatment control and does not satisfy positive-decay ISS.

**Adaptation / macro:** constructed 16-step two-target shift fixture tests both faster recovery and greater stationary error; not a learned adaptation test. Population mean closure tested for linear all-to-all mean coupling N=2,5,16,128 and falsified by variance-sensitive nonlinear interaction; no empirical micro-macro inference and no renormalization-group claim. Geometry on authentic bytes lacks context-specific human semantic labels, thus no semantic judgment accuracy can be scored.
