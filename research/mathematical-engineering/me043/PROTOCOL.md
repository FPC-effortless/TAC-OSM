## New architecture

96 observed samples, all real channels. Shared-channel normalization/context and full-history AR retained. Narrow 192->20->128 context encoder gives a cheap forecast using the shared SwiGLU horizon head. A learned router sees 16 observed context statistics +128 cheap latent values. A six-token native expert initializes fast32/slow32 from bounded cheap context, then applies unchanged native fast/slow/8x8 associative prediction-error steps to six causally paired observed patches. A learned sigmoid amplitude adds the native state to half the context latent. Both exits share all forecast-head coefficients. Hard deployment route q>0.5 computes the native branch only for selected channel-windows using actual indexed dispatch; no dense branch followed by masking. Does not promise constant-time streaming, learned actions, full world-model ability or global novelty of conditional computation.

All training computes both exits to prevent expert starvation. End-to-end objective is half-sum of both authentic future squared errors +10 AR-anchor drift +.005 sum squared corrections + router expected detached squared error/cost +.05 binary cross-entropy to the observed per-example benefit indicator. Router cost coefficients fixed {0,.001,.005} in train-standardized MSE units. These are three complete fitted candidates, not a learned causal decision or counterfactual action reward. Native seeding, recurrence, cheap pathway, shared head and router are trainable together. No claim that conditional inference saves training compute.
