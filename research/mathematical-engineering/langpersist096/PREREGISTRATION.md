## Information boundary and controls

The acquisition process receives only A and the checkpoint. It exports all
actual state plus clock, anonymous owners and source/model bindings. A separate
query process receives only those exports and Q. It has no acquisition array,
original source, records or targets as an input. The scorer alone reads Y and
labels. This is source-reviewed process separation, not an OS sandbox proof
against malicious actor code or arbitrary external stores.

Before Q, independently compare retained state, all-content zero reset, real
donor state and norm-preserving coordinate corruption. Preserve legitimate
clocks and binding metadata. Include every carried tensor: TAC matrices, waves,
concepts, prefix sums, lexical history, previous keys, upper state and logits;
GRU/SSM hidden state and cached logits. Feed the same64 Q bytes to every arm,
overwriting trivial lexical caches before the first target prediction.

Source growing-prefix versus streaming logits must agree within FP32
atol3e-5/rtol1e-4 on fixed constructed fixtures before real scoring. Checkpoint,
model weights and input artifacts must remain unchanged. Full reset must be
independent of A under matched clock/Q; donor, batch and owner isolation,
determinism and fixed-episode future poisoning are required integrity checks.
Failed source/boundary gates block a positive finding.

The raw-history control is a fixed3904-byte ring budget per stream including
16bytes of cursor/length state. It uses the same A then Q and a fixed order6
Witten–Bell suffix predictor with uniform base probabilities. Count tables are
temporary query computation, not free persistent storage. Greedy generation
feeds only its own generated bytes. No true future byte is fed during exact4.
Its acquisition, scanning, query/generation cost, model/state/metadata bytes and
process RSS are measured. A raw-ring win is preserved and precludes an
unsupported efficiency claim for compressed TAC memory.
