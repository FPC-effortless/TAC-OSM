## Candidate implemented

Source: src/tac_osm/variants/exchange_world_action.py. One complete native fast/slow candidate with 100,343 learned parameters by design (requires live CI validation). The source passes explicit entity IDs, an observed/missingness mask, current action, time and goal. Eight finite entity addresses have role-separated observed, *unverified predicted*, and externally verified values; unowned addresses are never silently evicted when capacity is full. Learned symmetric/antisymmetric features condition same-role consolidation. Content-addressed retrieval, prediction innovation, next-state mean/Laplace scale and an advisory action proposal share one trainable model.

The exchange math is classical: it does not implement electron spins or quantum destructive interference. An antisymmetric relation alone cannot enforce occupancy and is not proof of memory capacity. The actual collision rule is the identity-aware deterministic allocation. Persistent event IDs must come from authentic sources or justified episode-local identity contracts. Eight addresses are not arbitrary-length event memory. Role 2 has no automatic promotion, and missing observations never become observed facts.

**Not yet implemented or trained:** dense video JEPA, long-multi-horizon rollouts, flow matching, verified policy optimization, full CASM, learned inverse dynamics, causal intervention effects, calibrated uncertainty, real robot control or external pilot. Producing an action proposal does not authorize execution.
