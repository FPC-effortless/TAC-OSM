# LANGMEM080 — genuine publisher source event-specific associative contribution and read attribution

**Frozen before source execution.** Original trained dual 8×8 fast + 8×8 slow model from LANGMEM078/079, checkpoint seeds 1701/1702/1703; unchanged model/optimizer/RNG/PSF source SHA, actual original four previously exposed DEV publisher owners, 320 sequential original observed bytes per owner, no state reset within owner. This is an internal, **no-fit causal mechanism diagnostic**, **not** independent real long-memory success or exact byte/fact reconstruction.

### What one historical write means

At original observed byte index `a`, with original source prior write key w derived causally from previous observed byte context and value v from current observed byte, the original model writes
- `Q_fast(a) = beta_fast(a) * value(a) w(a-1)^T`
- `Q_slow(a) = epsilon_s * value(a) w(a-1)^T`
respecting t=0 nonwrite and source admission. Each source model later processes observed byte i, with right affine transitions `P_lane(i)`, giving the old particular event's surviving matrix contribution
`C_lane(a,t)=Q_lane(a)P_lane(a+1)...P_lane(t)`. **This is only one source write's latent matrix contribution, not the previous source byte itself or its exact future identity.**

### Frozen cohorts, metrics, controls
Anchors `a={32,64,96,128,192}` chosen by source clock only (not next-byte label). Lags `d={1,8,32,64,128,192}` when `a+d<=319`; exact registered 5×lags valid pairs per genuine owner/model. Process original owner0..319 sequentially. For each anchor and query clock t=a+d, the original model has seen raw[:t+1] only, and only then is raw[t+1] read for metrics. Original source clock, training receipt/owner identity/real raw anchor byte/hash, per-target label SHA all recorded; disallow cross-owner copying. Source positional cap_all was chosen after exposed DEV, applied identically to all source original checkpoint seeds.
- **Write survival:** `||C_lane(a,t)||_F/||Q_lane(a)||_F` and normalized raw `||Q_lane(a)||`; learned original fast gate α/β, slow rho/β/epsilon, upper product retention bound; spectral contraction exact-real bound but FP32 small floor noted.
- **Address geometry**: trained current observed query `q_t` dot source original old writer w_{a-1} (not retrieval accuracy), `||C_lane(a,t) q_t||`; for fast and slow report per-anchor/lane values and aggregation at each frozen lag.
- **Attribution to prediction:** counterfactual at **one query step only**. Take actual previous original native matrix before query clock t and subtract exactly the transported `C_lane(a,t-1)`, keep all other recurrent states, token, owner and clock unchanged, run one ordinary model source step (which still writes current Q_t); compare source next-byte logit/NLL with frozen unmodified logits. Source `C_lane(a,t) q_t` should match exact read-difference to tolerance1e-5 (fast projection original identity, slow source read mix learned). Evaluate helpful/harmful fraction based on signed `NLL_event_removed - NLL_full`, never claim intervention is full history replay or direct factual recovery.
- **Negative control:** subtract **zero** transported event and require bitwise identical logits; source affine step `N_next=N_prev P+Q` and old event survival obey original P at every t; checks require <=1e-5 max tensor deviation, no forged future-key labels.
- **Source label fingerprint:** original observed target `raw[t+1]` for exactly each of the registered pairs, identical SHA across seed models and original owners, source annotation independent of next-byte data. Original genuine event anchor byte raw[a] is observed by model at t=a, never used to choose the query or future label.
- Pair results include source current event and anchor identity, address/read norms, signed NLL lesion effect and true target correctness; aggregate by original lane and lag across three original trained seeds and four genuine source owners.

### Scientific nonclaims
The slow lane may hold a numerical event trace yet still provide near-zero or harmful true next-byte effect. Positive attribution to current prediction is not a proof the original source event's *content* was recovered. The intervention changes the old native matrix only at a single query; it does not re-run all later states without that earlier event, so it is an **instantaneous read-contribution attribution**.
