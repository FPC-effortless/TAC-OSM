# TAC bounded autoresearch operating contract

Inspired by Karpathy's autoresearch README/program.md (reviewed2026-10-29):
https://github.com/karpathy/autoresearch . This is an adaptation, not a copy of
its GPU runtime, safety settings, unlimited loop or experiment-deletion policy.
AGENTS/CHARTER/CODEX and operator execution levels remain authoritative.

- Read latest Issue472, original receipts/checkpoints and draft PRs; do not repeat
  completed experiments without a new falsifiable registered reason.
- One bounded capability question and small candidate edit surface per batch.
  Freeze source, evaluation harness, labels/splits, information boundary,
  parameter/exposure/compute/tuning budgets, hypotheses and access ceiling first.
- Preregister protocol and phone_queue CPU/GPU decision before execution. CPU
  default; no GPU quota without protected approval; no TEST/debugging/promotions.
- Existing corpus/DEV is exposed. Select on the frozen FIT/selection partition
  only, then report all predefined confirmation cases. Never relabel repeatedly
  tuned DEV as fresh TEST, or seek unlimited wins by repeatedly reading it.
- Commit candidate before measurement, hash evaluator/data/old checkpoint,
  run exact bounded budget and append every attempted trial, error and resource
  receipt to the ledger. Preserve failures and binary originals; no reset that
  deletes scientific history, no best-seed selection, no altered evaluator.
- Log NLL and bits per ORIGINAL byte, sample/target counts and per-seed outcomes.
  Lower predictive loss is not automatically intelligence, long-range retrieval,
  safety, factual source truth or customer utility.
- A keep decision means provisional internal follow-up only. Checkpoint promotion
  and independent qualification have their own strict gates. A failed gate or
  insufficient trial budget stops this batch; it does not authorize new quota.
- Equal wall time optimizes a platform-specific budget; it does not establish
  matched architecture compute. Retain applicable parameter, source/exposure,
  training/tuning and complete cost accounting; compare quality-cost frontiers.
- Account separately for weights, optimizer, carried state, context/source/cache,
  scan activations/workspace and runtime RSS. Measure latency/energy on actual
  deployment device before claiming a phone advantage. Customer inference offline.
- Independent source/evaluator signatures are required for qualification scopes,
  not ordinary authorized public FIT/DEV internal research.

First batch LANGMEMORY042: two fixed parameter-free position controls on original
five trained graph-free48D models. FIT-only choice precedes32 already-exposed DEV
confirmation targets per seed with genuine/donor histories and128/256/512 contexts.
No neural training. No automatic claim or implementation of dual-memory reasoning.
Every later batch needs a new bounded preregistration; this file is not a scheduler.
