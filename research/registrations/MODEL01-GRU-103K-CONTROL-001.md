# MODEL01-GRU-103K-CONTROL-001 — Genuine source-matched recurrent control

**Temporal lane. Register before first actual GRU source FIT.** The tested native TAC from [PR #502](https://github.com/FPC-effortless/TAC-OSM/pull/502) is a frozen 103,252-learned-parameter experimental model with fast32+slow32+8x8 gated associative state. Its three original 160-update real UCI374 FIT checkpoints and original DEV scores are Git owned and clean replayed. This study aims to check whether a comparably scaled familiar neural sequence model also learns the **same real point-forecast target** under nearly identical source budgets. This does not attempt a published gated-delta novelty claim.

- Exact official UCI374 appliance-energy publisher ZIP SHA256 `2fccf354445d886e7917620b0195db1f3e3e34d5a067a93b844694a4c561255a`, DOI 10.24432/C5VC8G. - GRU control is a **single standard unidirectional GRU layer** of 145 hidden units, standard 3 input features and 256-wide two-layer GELU forecast readout with a one-step persistence residual. Its exact actual trainable parameter count is **102,883**, non-dummy and deployed identically; native TAC exact count **103,252**, relative difference 0.3574%, less than compulsory 1% tolerance and both in 95k–105k.
- **Identical source inputs and histories:** 48 original past ten-minute appliance energy values with FIT-only mean and scale; daily deterministic sin/cos from the same original source positional index. Same 60min (six 10-min steps) forecast target and original eligible chronological windows. CAL quantile and DEV coverage/MAE/RMSE/interval score computed by the exact original `tac.score` function, not model-specific favorable scoring.
- **Same training seed and budget:** 1701,1702,1703; identical `torch.manual_seed`, NumPy seeded original batch sampler; verify SHA256 of every actual sampled FIT index matches source original native TAC `sample_order_sha256` for that seed; 160 AdamW optimizer updates × 64 samples, fixed lr=.001, decoupled wd=.01, smooth_l1 Huber beta=.5, clipped grad L2 <=1, no tuning, early stopping, or source/data change. Three seeds are the original existing native seeds, not 3 independent households.
- **Disclosure critical to fair comparisons:** 102,883 vs 103,252 parameter counts, identical examples/updates/seeds/optimization and source are matched, **but standard GRU and native TAC have unequal arithmetic FLOPs and memory traffic per update**, and original TAC design/hyperparameters benefited from earlier development inspection; no FLOP-normalized/compute-matched training or symmetric architecture-search budget is established. This experiment is therefore **a parameter/data/update-matched diagnostic, NOT a strictly fair architecture-superiority trial**. If GRU scores better/worse, do not claim algorithmic superiority without full compute/tuning controls and a truly independent cohort. CPU runtime parity itself is not required by owner.
- **Preregistered factual metrics** per seed on exact 1968 already-exposed source DEV predictions: original native checkpoint MAE/RMSE/90% empirical coverage and interval score versus new GRU same-domain numbers; compute paired source case-level differences if raw predictions are ultimately preserved. Report all seeds and both positive/negative metric directions, no median/seed cherry-picking.
