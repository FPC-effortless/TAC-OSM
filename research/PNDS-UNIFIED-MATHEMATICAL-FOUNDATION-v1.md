- **System 1 ME076–079, ME077A:** real trained native fast-only/mixture reactive physical predictors; persistence and motion-event failures retained. Core DIAGKEY004 is NOT silently transplanted into System 1.
- **Physical ME080–095:** native horizon-conditioned multimodal physics; ME094 distribution median coherence with full predictive gate FAIL; ME095 diagonal affine subfilter scan is mathematically parallelizable but the nonlinear full recurrent graph is not. ME095 capability not declared qualified.
- **Enterprise ME069–074:** observational workflow event/time state, source-EOR absorbing future law; matched GRU beat ME069 native NLL and ME073 has no fair matched multihorizon neural head-to-head.
- **Temporal, Edge-Lite, Counterfactual:** six-lane adapters, not necessarily trained neural models, and no established causal or deployment utility.
- **ES-WAM/ESWAM008–014:** observed source-identified entities and window-fed fast/slow attention/relevance, selected Lean role/shape properties, real traffic forecasting with low-speed failures; 256-frame observed windows are not infinitely carried memory.
- **Research qualification:** current 95k–105k fully useful learned parameter band; <=1% matched parameter counts; equal training data and **training compute**, NOT equal CPU elapsed time; authentic real-world primary evidence, original weights/checkpoints and no synthetic success promotion.

## New research handoff — append rather than overwrite

For every prospective mathematical architecture change, record:

1. **Independent variant/research version ID**; never overwrite a historical result or branch. Link the exact original source Git commit and whether a candidate is only a specification, software/tested mechanism, exposed real-development result or independently qualified real model.
2. **Complete computational graph boundary**: typed observations, action availability/lag, state variables and shapes, memory retention/write/read, time and causal semantics, decoder law and loss.
3. **Specific PNDS proof contracts**: boundedness, distribution consistency, scan/serial correctness, numerical tolerance and derivative behavior. Mark proofs **OPEN** until Lean compiles and the source matches the specification; add counterexamples where assumptions fail.
4. **Scientific original evidence**: trained active and deployed parameters, source splits and hashes, equal data/compute baselines, original checkpoints plus optimizer/RNG, independent replay status, authentic primary tests, real negative gate results.
5. **Failure-preserving ledger entry**: record pass/fail/uncertainty and independent-test restriction in [PNDS foundation evidence-ledger](https://github.com/FPC-effortless/pnds-lean/blob/main/foundation/v1/evidence-ledger.jsonl). Preserve immutable original artifacts in TAC-OSM.
6. **Update version coverage** in the [registry](https://github.com/FPC-effortless/pnds-lean/blob/main/foundation/v1/registry.json), and mark uncovered historical study IDs in the [archive gap log](https://github.com/FPC-effortless/pnds-lean/blob/main/foundation/v1/archive-gaps.json).

Do not conflate computational correctness with predictive intelligence: state bounds, normalized distributions and correct affine scans are analytic or software proofs **under assumptions**. Memory retention, causal interventions, forecasting superiority and customer ROI demand independent empirical evidence.

## Verification and release order

1. PNDS strict offline ledger/provenance validator, seven mutation/regression tests, full Mathlib/Lean build and theorem axiom inspection must pass before treating new formal properties as machine checked.
2. Source implementation gets real input-to-output Python equivalence and forward/backward finite-precision tests, preserving historical strict tolerances instead of loosening failed gates.
3. Genuine original matched 100k fit/evaluation and protected independent real source must pass registered original baselines; operational and commercial claims require their own evidence.
4. Both repositories remain draft/unmerged until individually reviewed. **Cross-linking does not imply source/Lean semantic equivalence or full historical archive completeness.**

The original TAC-OSM master plan and its negative result histories remain intact. This document adds a mathematical-engineering provenance interface, not a replacement history.
