# Canonical master addendum — restore previously implemented TAC memory remedies

**Date:** 2026-10-27
**Authority:** [Unified Master Research Plan](MASTER_RESEARCH_PLAN.md).
**Source-level working reconciliation:** [PAR-MEM-009](https://github.com/FPC-effortless/TAC-OSM/pull/518) (draft; its source-pinned audit reports independently verified only after CI passes).
**Scope:** no overwrite of original variants/checkpoints, no seventh model, no new trained capability, no change to protected real-source permissions or original evaluation protocols.

## Why this addendum exists

A new narrower parallel candidate reported low source writer-key effective rank (~2.67/8 at 256 recorded events) and failed long-event recall on previously exposed real UCI Beijing sensor records. It initially prompted an intention to design shared source-known write/read addressing and balanced writes. **Both mechanisms were already implemented and experimented on in older TAC research**. This is not an unexplored global TAC defect; it is evidence about the most recent simple time-aware candidate's memory code and training objective. Original implementations were accessible on historical branches, not necessarily included in the newer six-family branch.

The complete master plan already states that new capability studies must start by reconciling previous results, avoiding endless component microvariants and prioritizing real-world usefulness and checkpoint replay. This addendum makes the earlier concrete memory implementations explicit so they are not silently dropped from future consolidation.

## Historical source implementations that MUST be examined before another memory redesign

- [DIAGKEY004 original actual model source](https://github.com/FPC-effortless/TAC-OSM/blob/research/diagkey004-aligned-gated-retrieval-2026-10-23/src/tac_osm/aligned_associative_tac.py): write/read both use `self.address(keys)` from the same known key identity, value codebook is tied to retrieval decoding, separate retention and error-write gates, query is READ-ONLY, radius-four memory norm projection. Five-seed 99.84% synthetic immediate recall at 4096 steps **does not** qualify long-delay real-world reconstruction. Strict cross-host raw-logit replay exception remains, do not call whole strict replay passed.
- [ME100 source-aligned entity sensor core](https://github.com/FPC-effortless/TAC-OSM/blob/research/me100-entity-sensor-world-2026-10-25/src/tac_osm/variants/entity_sensor_world.py): source-owner plus source-hour and model-version guards, observed-only per-channel write admission and normalized evidence sum/mass, bounded associative affine prefix scan and direct read correction. Source-owned histories of 8/64/256 genuine hours show conditional point benefits on some small sensor-gap cases; source uncertainty coverage/full real gain gate **FAILED**.
- [LATFUSE004 2×2 actual neural implementation](https://github.com/FPC-effortless/TAC-OSM/blob/research/latfuse004-factorial-routing-capacity-2026-10-27/src/tac_osm/latent_fusion_004_factorial.py): two 8D heads or four 4D heads sharing 256 real FP32 memory cells, differentiable source-observed soft write routing, explicit route-balance and key-diversity objectives, fast80/slow80,16×80 source slots. Soft WRITE route entropy improves near 0.97–0.98 for 2H, and collisions are reduced; meaningful old-value retrieval and all-channel real forecasting **were NOT improved consistently**. Differences in hard/soft erase law confound the factorial attribution, and supported FLOPs >1% gap forbids certified 2H-versus-4H neural architecture superiority.
- [LATFUSE007 source-clock historical query](https://github.com/FPC-effortless/TAC-OSM/blob/research/latfuse007-historic-query-candidate-2026-10-27/src/tac_osm/latent_fusion_007_historic_query.py), [LATFUSE008 meaningful associative-blind fast/slow head](https://github.com/FPC-effortless/TAC-OSM/blob/research/latfuse008-matched-historic-query-control-2026-10-27/src/tac_osm/latent_fusion_008_nonassoc_control.py) and [LATFUSE018 actual source historical-content training](https://github.com/FPC-effortless/TAC-OSM/blob/research/latfuse018-real-source-content-training-2026-10-27/research/mathematical-engineering/latfuse018/RESULTS.md): source-known past event clock query, same-parameter comparator with useful fast/slow historical interactions, supervised real physical past-PM2.5 content loss and original full source/train-compute receipts. H64 trained associative model outperformed separately trained fast/slow historical head in 2/2 seeds but failed incremental read-versus-zero-matrix/source-prior in 1/2; later real time-specificity gate failed in both seeds. No independently qualified reliable historical memory.

## Current branch regressions/feature omissions are not universal TAC limitations

The newer TimeAwareParallelResidualWorld is a **narrower 96,639-weight and 154 FP32-scalar state** with 88 source-input prefix summary, 64-cell associative matrix and two clock scalars. Its current source-era 16/64/128 event history studies use frozen own write/read keys in an external privileged trace and show poor retrieval; a later address-diversity source probe yielded ~2.67/8 effective rank at 256 observations. It has no ME100 typed source owner/last-hour version guard in its returned recurrent state, no retained LATFUSE004 independent fast80/slow80, no 16 entity source slots, no 2H-soft routed 256-cell memory, no integrated source-known historical query with content reconstruction. It is NOT a complete consolidation of all proven mechanisms. Never compare `154 FP32` with ME100 `152 FP32 + metadata` or LATFUSE `1696 FP32 +16 flags` without accounting for their distinct scope, source metadata and external cache.

## Binding next-step research decision

1. **Reuse first.** Before registering a new memory mechanism, point to actual previous `src/` Git blobs, original source success and failed gates. A good initial integration target is already-existing DIAGKEY004 known-key read/write protection, ME100 source-authorized admission and identity guard, LATFUSE004 soft 2H/8D source heads and LATFUSE018 factual historical content loss, without discarding their baselines.
2. **Do not confound.** Initial scientific tests should separate addressing diversity, write admission/erase law, actual retained source value and deployed read utility. An 8D high-rank synthetic/Fourier key benchmark is only a geometry reference, not a trained ability. A privileged oracle writer key is not a deployable timestamp query.
3. **Preserve shared architecture promise accurately.** Keep the original ordered input-only affine memory schedule where its coefficients are input-dependent and scanable. Do not claim fully parallel nonlinearly state-coupled recurrence or the same 154-float budget when porting 256-cell LATFUSE source slots. Keep CED postscan candidate optional within existing six research families. PNDS is the authority for all Python/Lean mathematical transitions and proof boundaries.
4. **Capability-first, honest full evidence.** Validate a complete registered source-data historical retrieval and actual future utility on new independent authentic longitudinal events. Equal 95k–105k live model scale with within-1% active comparator parameters, training FLOPs, exact data/splits/optimizer and all five seeds; original model/optimizer/RNG/states and cold replay required. CPU wall time itself not forced equal. Zero-read, meaningful fastslow, stateless, recent-value, source-identity priors, GRU/SSM as appropriate. Source timestamps and availability must be causal; never expose future/source-oracle values to the query. No retuning on already-exposed 2014 or protected 2015–17 numeric cohorts.

**No claim that these ingredients already solved general long-term memory.** The reusable *mechanism implementations* exist; whether their combination yields genuine causal, memory-specific source benefit remains an open hypothesis. This addendum is a scientific lineage correction, not a release or authorization to consume protected source data.
