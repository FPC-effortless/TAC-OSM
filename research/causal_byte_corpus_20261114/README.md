## Implemented contract

`load_byte_corpus` accepts a raw manifest SHA pinned outside the mutable corpus,
validates manifest/file/license/Git-blob/length identities, bounded reads and
safe nonsymlink local paths. Unknown/protected roles, duplicate document IDs and
identical bytes across FIT/DEV are rejected. It enumerates only registered files.
The Unicode supplement keeps its original source-role identity while mapping to
FIT for iteration. Files/model/filesystem must be owned and quiescent; no hostile
filesystem/atomicity/cryptographic provenance guarantee is claimed.

`causal_byte_chunks` requests FIT or DEV explicitly. For original source of length
n, chunk input offsets[a,b) have inputs raw[a:b] and labels raw[a+1:b+1], where
0<=a<b<=n-1. The intervals partition[0,n-1), so targets1..n-1 occur once per document.
Final partial chunks remain; no padding, artificial EOS, concatenated source or
cross-document label pair. Byte IDs0..255 are lossless; no multilingual competence
follows from codec completeness or62nonASCII FIT targets.

`model_input_values` projects only input token values and stream IDs. These values
need local integer-tensor construction before invoking the existing model. Whole
sequence chunks contain later *observed* inputs for later predictions; actual
model causal masking/time/gradient behavior is still a separate requirement.
Stream IDs include role/path/source hash for metadata ownership only, never token
features; source hashes do not prove prediction-time causality.

`incoming_byte_state` forces None at every document start. Continuations must
have exact stream identity and next offset; wrong role/stream/order or missing
state fails. `outgoing_byte_state` stores only opaque state and next offset.
State objects are returned unchanged, never cast/copied/detached. These metadata
checks do not authenticate state contents/history or replace727/728numeric/binding
guards. No training runner or deployed runtime silently adopts this adapter.
