# TAC-UNIFIED-004 exploratory preregistration

Five original 003 seeds. Independent fixtures at seed+50000 onward. No change to prior results. Three diagnostics, not a full native CSL fit.
A: same 003 codebooks/tables and 128 x 1,024 action chains per seed. Compare exact-eight candidate elimination, fixed-five summed Hamming, and soft adaptive. Initial clean audit quantile from known 8-flip observations (95th percentile). For each 1,024-action chain, process groups of 64 temporal steps across sessions; audit first 1/16 decisions with five observations, otherwise stop at nearest/second-nearest cumulative distance gap >= max(10, 2*q-6) and first observation residual <= q. If residual exceeds q or audit discrepancy high, use five. Recalibrate q from rolling audited consensus residuals (last 512, finite-sample 95th percentile); no true label at controller. Nonconformity uses observed distance to five-view pseudo-label, not distribution-free coverage. Evaluate exact8, 7/8/9, heavy-tail mixture (8 or 14 flips), and correlated common 8 flips shared by all views. Gold only for scoring. Record action errors, exact actions per chain, final state, reads, and elapsed time. Diagnostic target: at least 99% final state with <3 reads on exact8 and variable789, no more than 1 point deficit vs fixed5; report other regimes without promotion.
B: use exact 003 learned local transition tables; 32 eight-bit blocks, random directed matching of 16 pairs. Unknown edges, source action 0 flips target bit 0 conditional on pre-action source bit 0; target action 1 selects local table 1 or 2 depending on source bit 0. Discover cross-writes via controlled probes of each action at all-zero and source bit0=1. Discover cross-reads via controlled single-block bit0 variation and compare target transition at local values 0..255 (bounded known hypothesis class). Learn action effect masks/table choice, build graph, compare local and dependency-aware topological planner on 64 fresh reachable goals per seed. Verify against true environment, no goal or graph labels in discovery. Include cyclic matching control, abstain on cycle. Report graph exactness, plan success, intervention costs, lengths, latency, and independent layer width (not actual parallel speed). Gate: graph exact, 100% goal completion and cycle detected; no general causal discovery claim.
C: five-seed 96-dimensional synthetic cue task. First 32 features are familiar +/-1 binary codebook with 2 flips or unfamiliar random +/-1; remaining 64 encode action by nonlinear paired signs (product carries code), with continuous jitter. Train one MLP on balanced labelled demonstrations, matched evaluation of fast Hamming, always-neural, hybrid (route if nearest distance >4 or margin <4), separate familiar/unfamiliar accuracy, neural fraction and wall time. No regime labels passed to routing. Gate: >=99% hybrid accuracy and no more than 1 point below neural, <70% neural calls. No native CSL integration. All failures retained.
