## Why this experiment exists

This experiment asks whether **authenticated entity identity and truly observed evidence-gated admission** can isolate and retain relevant longitudinal history for an observed delayed operational outcome, instead of optimizing only high-frequency next-joint-position MSE.

## Registered architecture/controls

Three equally source-typed native models with exactly the same 95,907 registered trainable scalar weights, input dimensions, 664 FP32 floating carried bytes (88 additive+64 entity memory+14 previous observation), identical initial weights and actual training episodes:

A. **entity_all**: eight individually fixed source identity rows, admits all present authenticated measurements through learned source-known gates.
B. **entity_priority**: same row identity and learned gates, permits write only if as-of observed relevance≥0.75.
C. **entity_none**: no rows ever written; model otherwise same source/event/weights/observed features (negative no-memory).
D. **global**: historical original associative 8×8 matrix that does not use externally authenticated slot; contextual comparator but **not equal effective information**; its result is never enough to establish fair source-matched superiority.

A source-only memory update in slot s is `M'[s]=(1−β_eff)M[s]+β_eff v`; all seven other rows EXACTLY unchanged when s is addressed. `β_eff=sigmoid(beta_logit)*(1−sigmoid(alpha_logit)/4)` and zero if observed_priority below threshold in priority mode. Source decision is independent of previous matrix contents. Thus each row update is an affine map and its chronological parallel prefix can be computed with bounded O(T·64) work and O(log T) depth; streaming step is O(8) memory arithmetic. Dynamic eviction has NOT been added; a reader cannot silently treat it as implemented. Equal nominal parameters/state do NOT establish full compute equality: all write/update/read flops and gradient passes must be profiled.
