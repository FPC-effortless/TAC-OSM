# S1MOTION001 — first genuine-source System 1 neural preflight and training

**Preregistered 2026-10-26 before any new model fit or DEV scoring.** Source root: TAC System1 draft PR #413 and six-family v1.7 parallel core; this study is NOT model seven. This document is a new prospective protocol; previous EWA002 results on this dataset are already public, so this is **not** a previously unexposed independent domain.

## Authentic source and prediction task
- Public MIT-licensed real LeRobot ALOHA static candy bimanual recordings (`lerobot/aloha_static_candy`), locked publisher snapshot **6728831ef9674b74f3ce20bf517890e9ee20b0d9**. Fetch the sole consolidated `data/chunk-000/file-000.parquet` and checksum it before processing. No synthetic training/evaluation substitutions.
- 14 observed joint states at frame t and 14D **prior logged action** from frame t-1, with timestamps, exactly observed at forecast time. The logged action is observational evidence; command physical execution semantics and intervention effects are not established. Predict **measured joint state at t+1**.
- Secondary target: whether the *measured* mean squared joint motion `mean((state[t+1]-state[t])**2)` exceeds the **90th percentile determined from FIT only**. This is a measured high-motion **proxy**; it is NOT adverse harm, episode success/failure, collision or hazard. The existing candidate's `adverse_event_logit` tensor is reused purely as a binary proxy logit. No adverse-risk claim permitted, even if proxy metrics are strong.
- Episodes **0–24 FIT**, **25–34 DEV**, **35–49 protected UNTOUCHED for this study**. Prior EWA002 has scored episodes 25–49 on other baselines; avoid falsely calling this a virgin external test. Only the first 257 recorded frames may be used from each permitted episode; enforce positive timestamp gap and consecutive frame indices.
- The consolidated publisher parquet physically contains all 50 episodes. Process **only** rows with episode IDs <=34; do not instantiate/normalize/train/evaluate on 35–49, but do not claim their bytes were never downloaded.
- FIT-only per-coordinate mean and standard deviation for states and prior logged action; physical measured targets standardized by FIT state parameters. FIT-only delta_scale = 95th percentile absolute standardized physical next-frame changes, min 1e-4. No hindsight in event features or normalization.

## Preregistered arms and budgets
- Exactly **three** seeds: 26001/26002/26003. Whole-model train from scratch on FIT only. System1ParallelWorld default: 95,907 active/deployed parameters. Matched GRU controls use input28, hidden160, linear29 for 95,869 active/deployed parameters (**0.040% difference**); same train-only delta scale and sigmoid / softplus heads.
- Same optimizer AdamW, learning rate 0.001, same mini-batch (8), same window length (32), same **192 optimizer updates** per seed, same sampled FIT source windows, same loss/grad clip and split. No extra tuning/hyperparameter sweeps, same initialization seed (architecture weights differ).
- Frozen objective: next-state MSE of normalized outputs **+ 0.1 × BCEWithLogits** for high-motion proxy + **0.01 × mean Gaussian standardized NLL** using positive predicted dispersion. No class-dependent weighting, no tuning based on DEV. Both architectures implement exactly the same loss.
- CPU thread=1 for reproducible cost audit; report active parameter count, source episodes/frame labels, same exposure count, training walltime, approximate PyTorch profiler FLOPs subset where supported, plus CPU p50/p95 per-step stream latency (not device SLA). Parameter parity alone does not demonstrate FLOP parity. If measured compute mismatch exceeds 1% or FLOP completeness is inadequate, **do not claim a fully fair FLOP-matched architectural win**.
- Report separate persistence and finite-difference **constant velocity** forecasts (2*x[t] - x[t-1]) in actual joint units, with no fitted parameters. This strong physical reference must be beaten; merely beating persistence or GRU is insufficient.

## Original-score and acceptance gates
- First original DEV pass only, one complete score per frozen seed; do not re-fit or choose scores after examining DEV. Record per-episode squared error, high-motion subset error, threshold, AUROC, AUPRC, Brier, cross-entropy, and RMSE/MSE in source units. Comparisons are episode paired; no IID per-frame confidence claims.
- A provisional predictive advantage needs **every seed's System1 next-state MSE <= 0.99 * strongest(velocity, persistence) on DEV**, no high-motion MSE > 1.05 * velocity, **and** System1 MSE < matched GRU for every seed. Report proxy AUPRC relative to GRU and empirical positive prevalence, not an external adverse event advantage. Otherwise research full gate FAIL.
- This study cannot confer real-world superiority or policy/actuator safety, regardless of scores: independent untouched cohort, authentic adverse outcomes and intervention decisions, robust repetitions, complete PNDS exact-real/IEEE/AD source refinement and device timings remain open.
- Preserve source SHA, original all-seed score JSON, logging/provenance and negative gates. Never change old ME/EDGEACTION/EWA artifacts. CI test fixtures may be constructed solely for engineering checks, never for measured capability.
