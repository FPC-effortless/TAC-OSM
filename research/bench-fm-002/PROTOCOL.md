# BENCH-FM-002: Evaluate TAC-OSM where Google's foundation models are designed to work

**Registered October 21, 2026, before the new test measurements are scored.** Research only, not architecture or commercial qualification.

## Two separate real-data questions

**Track A — TimesFM 3.0 multivariate forecasting.** Authentic hourly ETTh1 source from the original ETDataset publisher. Fixed TRAIN first 8,760 hours, already used development next 2,880 hours, TEST original later 11,640 onward. 7 actual channels; 24/96-hour forecast horizons; 96 shared chronological forecast origins, selected without looking at target values, all 7 channels scored. Native TAC two-timescale recurrence, retrained with a declared 2-horizon task head on the TRAIN segment, 250 identical AdamW update budgets for 2 original random seeds. GRU independently trained on precisely same input/targets and update budget. Ridge, last-value, and previous-24h seasonal controls. TimesFM 3.0 zero-shot with **96-hour** history for equal input to trained TAC and separate **512-hour** context, which exposes the foundation model's strength on longer histories. All model predictions for exactly the same target timestamp and seven channels. METRIC train-normalized MSE/MAE, horizon breakdown; no result selection or retuning on new TEST after evaluation. Validate source audit/checkpoints before scoring. This new TAC is the ME035 *recurrence mathematics* with a freshly trained 24/96h head; it is **not** the original ME035 checkpoint, which exported 1/6/24h. New checkpoint SHA/parameter size and labels reported. Original ME035 training/development evidence is unchanged.

**Track B — TabFM real mixed tabular classification.** Official UCI Bank Marketing bank-full.csv, original official outer dataset ZIP SHA256 **e0bf5f5de5b846e2f18e9d90606637267d46dfa260e0f17bb12e605db5efbeb4**. Binary real deposit outcome. Stratified supervised source examples selected ONLY from first 70% of original chronologically ordered interactions; holdout from final 20% never used for model selection. **512 training examples; 256 held-out examples**, with fixed sampling seeds established in source before training. Column `duration` deliberately excluded from all arms because it is unavailable for pre-call decisions and leaks post-contact information; 15 original mixed numeric/categorical columns remain. Official Google TabFM 1.0 PyTorch pretrained classification weights; .fit passes 512 rows as in-context labels and the pretrained model weights remain frozen. The public Python package exposes v1.0, **not** the v1.1 import, so do not label 1.0 results as TabFM 1.1. New train-from-scratch TAC-inspired fast/slow tabular feature recurrence, logistic regression, histogram boosting and a conventional MLP, same 512 labeled source examples. Only a declared *feature-wise TAC adapter*, **not** a previously trained general tabular TAC checkpoint; order of columns is fixed and not claimed to correspond to temporal entity events. Report ROC-AUC, average precision, Brier, logloss and sample counts; zero-shot-versus-task-trained status explicit.
