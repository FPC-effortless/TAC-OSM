# Model 02 — Original Backblaze 2013 source-only evidence

**This is verified original publisher data acquisition and schema audit, not fitted/scored model skill.** Run [#40467078367](https://github.com/FPC-effortless/TAC-OSM/actions/runs/40467078367) fetched and verified the official original [Backblaze Hard Drive Data](https://www.backblaze.com/cloud-storage/resources/hard-drive-test-data) 2013 ZIP from the Backblaze publisher. Backblaze allows derivative commercial uses but prohibits sale of the dataset itself and requires credit.

Original ZIP SHA256: `7f5a53e79b16e695b4b034955806bb3bb194534b169f6eca460dfd3dc48096fe`; compressed 80,983,520 bytes. Tested: fourteen continuous days October 1–14, 2013; 12,600 genuine drive-day records, **3 recorded failure flags**; 900 records/day. These counts describe the exposed sample; they are not population-level failure rates. The original scan also observed `smart_198_raw` missing in every selected row, whereas `smart_5_raw`, `smart_9_raw`, and `smart_197_raw` were present in the source columns and all selected rows.

Permanent condensed per-day SHA256 and counts are in `MODEL02-BACKBLAZE-2013-EXPOSED-SOURCE-AUDIT.json`. The original original CSV ZIP was not committed, and no drive serials or raw publisher rows were redistributed. The Actions source evidence artifact is short-lived, but the ZIP SHA and daily source SHA fields permit repetition against the original public source.

An initial job [#40466871746](https://github.com/FPC-effortless/TAC-OSM/actions/runs/40466871746) failed before processing data because the ZIP guard rejected ordinary directory metadata. The correction skipped directories without extracting anything and retained zip-slip path checks. The subsequent original source run and constructed hostile-source tests passed.

**No fitted event-risk model:** 3 observed failure flags and 14 days are not a credible statistically qualified rare-event training/evaluation sample. No true source publication/available-at time, fixed unbiased prospective source enrollment, missing-identity censoring verification, or independent outcome provenance was established. The audited days are exposed development only. A much longer pre-registered original cohort with valid event/censoring denominators is required before classical delayed-risk fit, and architecture-specific claims still require equal informational input and matched neural parameter/data/compute budgets. No protected future date windows are opened or promoted by this source audit.
