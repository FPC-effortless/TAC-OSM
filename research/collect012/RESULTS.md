# COLLECT012 — completed internal language learnability

All nine preregistered actual TAC-OSM fits completed 1,024 FP32 AdamW updates.
The final checkpoint was fixed before training; no best-DEV selection occurred.
The two phase variants learned next-byte prediction from original Tiny Shakespeare
bytes without a parser, key/role targets, frozen C10 frontend or support filter.

Units are nats per next-byte target. The same 64 exposed-DEV windows/8,192
targets are reused across models; seeds do not multiply the unique evaluation
cohort. Removing the added memory output worsened DEV loss in every phase/hybrid
seed. This supports a contribution from that path, while native TAC carried
banks and SSA remain active. It does not isolate the benefit of preconditioning.
The local-attention reference is TAC, not a standalone Transformer.

The shared 128-byte-context recipe used batch 4, learning rate 0.0003,
betas 0.9/0.95, decay 0.1 and clipping 1.0. Each model received 524,288 TRAIN byte
presentations with replacement, about 0.522 TRAIN equivalents. This is an early
learnability pilot, not convergence or competitive language-model evidence.
Parameter counts and token budgets align, but FFN allocations and state
geometries differ and complete training FLOPs are unmeasured. No compute-qualified
architecture winner is eligible.

## State and failure diagnostics

One-owner retained generation tensors were 677.125 / 167.125 / 71.125 KiB for
attention / wide phase / hard hybrid at both 256 and 512 generated bytes.
These exclude weights, optimizer, BPTT, allocator and Python overhead. CPU
optimizer steps averaged 0.253 / 0.739 / 0.794 seconds on separate workers;
this is an observed implementation cost, not a hardware-controlled speed ranking.
All 18 temperature-0.8/1.2 generation executions stayed finite for 512 bytes.
Semantic coherence or reliable long memory was not established.

A frozen-component curvature diagnostic (36 cells) found that at 256 records,
32 active keys and 16 histories per seed, full curvature retained 100% maps;
block4x16 and diagonal controls retained only 22.92% and 0% on average.
Their curvature payloads were 16 KiB, 4 KiB and 256 bytes respectively.

A subsequent predeclared fresh-history spectral diagnostic (12 cells) retained
100% maps in all three seeds at rank 32 (48 maps total), using an 8.25 KiB
Gram sketch/residual diagonal rather than 16 KiB full curvature. Ranks 8/16
retained only 6.25%/2.08% maps. This streaming SVD/Woodbury implementation took
about 17 times the full operator time in the fixture, with temporary workspaces.
It is a bounded 32-key component state saving, not a speed or LM result.
This applies known matrix approximations; no new general algorithm is claimed.

The actual phase/hybrid graphs read before writing. A no-fit gradient diagnostic
found zero current-value immediate gradients through memory in all four layers,
while earlier values received sequence gradients. Write-before-read restores
the local gradient in an analytic/FP64 operator fixture but has not been trained
here. It is existing DeltaNet practice, not a new invention. Routing used all
four banks in every observed hybrid layer, with largest-bank shares up to 96.09%;
utilization is uneven, and semantic specialization is unproven.

The next controlled repairs are write/read ordering with a current-value control,
cheaper incremental spectral updates stressed above 32 keys, and separate read
selection/write admission with explicit routing-utilization measurements. None
is counted as a trained improvement. Stress-sharing was not implemented.

## Audit and preserved evidence

The cohort contains 9,216 full-fit optimizer updates plus 32 separately charged
local smoke/replay updates, 4,718,592 TRAIN presentations and 45 immutable
model/AdamW/RNG checkpoints. Summed recorded optimizer time is 91.43 CPU minutes;
zero GPU quota was consumed. All nine trained-source audits passed checkpoint
closure, 1,024-step journal/AdamW consistency, future-byte poison invariance,
owner isolation and whole-graph FP32/64 reference logits/state/gradient fixtures.
Fresh-process remote replay was exact in Torch 2.5.1 CPU; local Torch 2.15 replay
used declared 2e-5 absolute/relative tolerance. Full formal IEEE/AD qualification
remains open. Only initialization replay, not mid-training trajectory replay,
was executed.

Protocol disclosure: the registration lists generation sample seeds
12011–12013, but the frozen evaluator uses sampling RNG 120100 for every model
and temperature. All samples are retained as fixed execution diagnostics;
independent sampling-seed coverage is not claimed.

All three final internal single-model resource gates pass with
`eligible_for_architecture_superiority: false`. Protected TEST was not read;
independent qualification, promotion and full FLOPs matching remain open.
