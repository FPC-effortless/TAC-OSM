# Next-byte evaluation contract

The frozen scoring unit is a UTF-8 source byte. Preserve each document's original bytes, including whitespace and line endings. Reset model state between documents and every 256 scored targets. Score every transition within a document once, including trailing partial windows. Each document's first byte has no predecessor and receives no score. This evaluator measures bounded-window prediction only. Long-context dependence requires a separate registered study.

Call score_documents(predict, documents, device=...) with an evaluation-mode model. The prediction function receives only a tensor of input byte IDs and returns logits with shape [1, time, 256]. For TAC or GRU return model(ids)[0]. For nanochat use model(ids). For the official Mamba LM use model(ids).logits with a 256-byte head. Provide an ordered list of document IDs, externally committed SHA-256 digests and original bytes. A final one-position input receives a fixed trailing zero because nanochat's full-sequence implementation requires more than one input. Only its first position is scored. A causal predictor must ignore the later padding.

For each target the scorer subtracts its logit from the log of the sum of exponentials in FP64. It sums nats across documents, divides by the total scored bytes, then divides by ln(2). Per-document target counts and numerators support paired analysis. Empty and single-byte documents contribute zero targets. Mismatched hashes, duplicate IDs, invalid UTF-8, invalid logits and zero total exposure fail. A signed manifest, independently controlled source set and frozen cohort checkpoints are separate requirements for a qualified held-out comparison.

Run the four constructed tests with python -m unittest discover -s research/language-comparison/evaluator. They check uniform 8 bits/byte, repeated and changed byte predictions with known probabilities, window boundaries, UTF-8 weighting and invalid records. This pilot opens neither DEV nor TEST.
