# WikiText-103 native CSL exploratory FIT pilot

The owner explicitly authorized a local CPU FIT-only pilot on 19 November 2026. The three arms are the selected 10M TAC-OSM, size-matched upstream nanochat and stacked GRU constructors frozen in ef34cd04419026cd42412668c7a107211f8fc01b. Local weight files and optimizer state stay outside Git. This is a separate owner-authorized pilot. Qualified comparative training remains subject to the repository's signed prefit gate.

Use the first 512 records from seed 10301 of the frozen WikiText-103 raw training order in ../wikitext103/FIT_RECEIPT.json. Each of 64 batches contains eight distinct 257-byte windows from within single UTF-8 source rows. Give the model only the first 256 byte IDs of each window with fresh state. Score its logits against bytes 1 through 256 outside the model. Use every target in the denominator. The three arms must have the identical ordered input digest, exposure and byte scoring. Keep validation and TEST closed.

Initialize each model at seed 10301. Native uses its selected inverse-width initialization. All three use FP32 learned weights, their registered implementations, FP64 next-byte cross entropy, CPU with two Torch threads, AdamW at fixed 0.0003, betas (0.9, 0.95), eps 1e-8, weight decay 0.1 on trainable parameters, global gradient norm clipping at 1.0. No tuning, early selection or alternative optimization run. Abort on nonfinite loss or gradient. Live counts must be 10,103,943 TAC, 10,092,770 nanochat and 10,103,552 GRU at start and end. Limit each arm to 64 optimizer steps, 131,072 target bytes and 900 seconds wall time. Run sequentially in the order TAC, nanochat, GRU.

Record every pre-update batch loss, gradient norm and elapsed time. Report first-eight and last-eight mean training loss and fixed FIT byte score before and after training. For the fixed FIT score use batch IDs 0, 16, 32 and 48, comprising 8,192 target bytes. These bytes also train all models. Primary diagnostic comparison is final fixed-FIT bits per byte (total nats / target bytes / ln 2). Save final weights, optimizer state, seed, completed update count, RNG, model identity and input hash locally. Verify on a fresh process by loading the original checkpoint and recovering the exact fixed-FIT predictions digest and byte score. This pilot neither selects a winner on held-out language nor establishes Mamba-3 performance or trained deployment cost.
