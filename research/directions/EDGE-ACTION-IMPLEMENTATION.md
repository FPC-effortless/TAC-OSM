### Exact graph and causal boundary

Let `H_t = {(x_i,u_{i-1},valid_i,time_i)}_{i<=t}` be **actually observed states and previous logged source actions**. Encode each observed pair and precompute the memory-independent gates and address schedule; apply the existing row-right affine update

`M_i=M_{i-1}P_i+Q_i`

through the original associative prefix for batch execution. A query for proposed same-time command `u_t^q` constructs a query embedding from **actual final x_t and candidate command** and retrieves `r(u_t^q)=M_t k(x_t,u_t^q)`; it then produces `xhat_(t+1)(u_t^q)=f_theta(x_t,H_t,r(u_t^q),u_t^q)`. This head is vectorizable across **Q alternate inputs**. The new output proposal includes an inherited-source next observation estimate, ensuring inherited weights remain on the active gradient path.

This query is NOT written to `M_t`; it cannot cause the model to hallucinate that any proposed command was executed. Only when a future *measured* source transition is received may its state/evidence be admitted. The target `x[t+1]` must never be read at time `t`. Caller owners and observation hours are guarded; simulated dropouts must hold state and advance requested horizon rather than being scored as invalid forecasts. The current query is **one-step only**, with no calibrated uncertainty forecast; a future trained model must separately address open-loop multi-step state uncertainty.

The inherited core carries 88-dimensional evidence sum + 8×8 matrix = 152 FP32 values or **608 bytes / entity**, plus count, owner, clock, model version tracking and Python/runtime/weight storage. Candidate-query memory, activations and additional metadata are separate. The affine scan has O(T) fixed-8×8 work and O(log T) theoretical scan depth, NOT an end-to-end O(log T) global graph or measured sub-millisecond latency.
