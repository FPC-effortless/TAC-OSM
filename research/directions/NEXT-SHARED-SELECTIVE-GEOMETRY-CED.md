## 0. Scientific thesis and stop rule

**Question:** Can a source-authorized, entity-aware *selective* memory that uses bounded geometry and post-scan concept refinement improve authenticated delayed-state retrieval, transition/motion forecasts, and eventually decisions, **without sacrificing the exact associative input-only scan, fixed-size primary dynamic state or reliable streaming updates**?

The new system is a **single experimental branch of the existing six-family shared TAC core**, NOT six replications, a DeepSeek transplant, or a new invented seventh architecture. Retain ME097/098/099 as frozen reference implementations; ME099 remains 4/5 full seed passes, full capability gate FAIL, exposed 13 ALOHA DEV episodes, and worse NLL than FIT-moment reference. Retain ESWAM012 long-256-vs-short-8 negative evidence (including [QUAL001 draft PR386](https://github.com/FPC-effortless/TAC-OSM/pull/386)), DIAGKEY004 zero-distractor-only capability, ESWAM013/014 moving-vs-low-speed trade-off, and the PR331 CED implementation (UNTRAINED) as a separate original historical source. Do not tune again on those DEV records or open protected TEST for convenience.

The core null hypotheses are: (H0-1) long entity history provides no additional authenticated predictive information beyond recent history or strong physically informed controls; (H0-2) learned admission/lookup/geometry/CED does not improve relevant long-delay retrieval and future-state prediction at matched training resources; (H0-3) bounded selective computation does not improve measured latency/cost at matched skill. All outcomes, including FAIL, remain in versioned research evidence.

## 1. Source literature: what is actually borrowed

- [DeepSeek-V3 technical report](https://arxiv.org/abs/2412.19437): auxiliary-loss-free router load-bias **for MoE expert balancing**; transfer to entity admission is a new TAC hypothesis, NOT a guaranteed way to stop write rejection.
- [DeepSeek-V4 model card/report](https://huggingface.co/deepseek-ai/DeepSeek-V4-Flash): mHC, hybrid **CSA/HCA** retrieval/compression and Muon optimizer at large scale. Existing techniques, not TAC inventions.
- [mHC paper](https://arxiv.org/abs/2512.24880): residual-stream manifold-constrained mixing. Its stability claims cannot automatically be applied to unbounded memory state or full neural gradients.
- [DeepSeek-V4.1-Flash model card/report](https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash): 20 causal-encoder + 20 decoder layers, **encoder-final projected decoder global KV**, CSA2 Full/Reindex/Reuse, Engram conditional memory, Single-Pass mHC, SWA bounded replay. This is DISTINCT from TAC's preexisting *Concept Exchange Decoder* (CED) in PR331, a six-concept / four-refinement-iteration design. Neither name means one implements the other.
- [Conditional Memory via Scalable Lookup (ACL 2026)](https://aclanthology.org/2026.acl-long.226/): Engram/DSE uses n-gram hashed learned static embeddings. Proposed site-map/spatial lookups are an ANALOGY and require authentic map/version/source authorization; hash lookup has expected constant-time behavior under assumptions, not worst-case proof or guaranteed zero collisions.
- [Native Sparse Attention](https://arxiv.org/abs/2502.11089): hierarchical compressed context plus fine-grained sparse selection. Do not claim a 1M-token context for TAC or copy LLM KV cache bytes as TAC's per-entity state.

**Unverified user-supplied premises** (not measured facts in this registration): 205 of 266 / 77% write rejection in a specific traffic admission protocol, 3.4x–5.3x CPU speed advantage, 15% future rejection target, universal per-token cache bytes for MLA, and a DeepSeek "safety" bounded-replay guarantee. Locate original source/script/receipt before treating any as baseline or numeric gate; a write rejection rate is not a quality or safety metric without source utility and false-admission costs.

## 2. Computational graph: preserve what is actually parallel

For B batches, T original ordered events, N source-authorized entities, D=14 example physical observables, and entity ID/time/missingness/provenance, define causal input e_t = encoder(o_t, a_{<t}, observed_delta_t, authorized_metadata). The 8x8 matrix memory is retained. Retain input-only gates independent of previous **associative read** for the same scan:
  M_{t+1}=M_t P_t+Q_t,  (P_t,Q_t)=G_theta(e_{<=t}, valid_t, known_context_t)
where scheduled gates are produced by an allowed causal prefix or precomputed input schedule, not by M_t or postscan CED outputs.

For first segment (P1,Q1) followed by (P2,Q2):
  (P1,Q1) * (P2,Q2)=(P1 P2, Q1 P2+Q2).
This composition is associative, enabling parallel prefix scans with O(log T) **span of the affine scan** and online O(1) per-event state update *at fixed dimensions*. The total neural graph can include nonlinear encoder, causal prefix, depth-K CED and sparse retrieval; it must NOT be labeled O(log T) end-to-end unless separately proved. The original serial DIAGKEY gated-delta does not become losslessly equivalent merely by using the same dimensions.

**Causal-information invariant:** output at t may depend on e_{<=t} and authorized static data published no later than t, never final Z_T when training forecasts for t<T. For online output, project final current Z_t once. For batched per-t outputs, either project each causal Z_t separately or use a versioned prefix-access memory with strict triangular mask. An encoder-final projected global cache from the full training sequence at every historical step would LEAK FUTURE.

## 3. Integrated architecture, mathematically specified

### 3.1 Entity authority, geometry and adaptive bounded admission (primary hypothesis)
Authorized entity labels and site-specific valid-time map metadata, not posthoc matched future IDs, define eligible slots E_t. Each entity j has source-only relevance logits s_{j,t} and controllable load bias b_{j,t} based only on previous occupancy and observed write/eviction diagnostics:
  a_{j,t}=s_theta(e_{<=t},id_j)+b_{j,t},
  b_{j,t+1}=clip(b_{j,t}+eta*(u_target-u_{j,t})-xi*eviction_{j,t},-B,B).
The equation is a **candidate control law**, not the DeepSeek MoE algorithm transplanted unchanged. Define capacity-constrained top-k/soft assignment with explicit masks; enforce unique authorized entity ownership, no cross-entity contamination, expiry/source provenance, eviction/overwrite traceability and invariant admitted_count<=slots. Continuously learn relevance from **damage to authenticated future state prediction/retrieval when one event is removed**, and preserve current-state decision cost where observed; never use synthetic rewards to qualify a skill. Gradient routing and admission-control bias must remain causally scheduled before the affine scan if parallelism is claimed. If admitted importance depends on previous M read, isolate a sequential control step or a separate read-after-scan corrective stage and account for its latency/semantics.

Do not use admission >=85% or rejected writes <=15% as a primary gate: filling memory can cause destructive overwrites. Report accepted useful events, rejected useful events, bad admissions, entity collisions, tracked lifetimes, false motion and actual future error.

### 3.2 Static spatial knowledge outside the primary dynamic state
Optionally define L_t = Lookup(hash(site, original coordinates/grid, map_version_as_of_t)) with validity, missing-key and collisions explicitly surfaced. Train/fit codebooks using FIT-authorized data and legitimate published maps only. Static codebook is read-only during an observational forecast; dynamic source events and transient actors are NEVER silently stored into static maps. Compare (i) no static lookup, (ii) same static information fed as ordinary input, and (iii) explicit static lookup, at equal factual information and measured total parameters/bytes/I/O. Do not claim the 608 B dynamic state now retains *100% more dynamic information* without ablations. The codebook occupies separate actual memory/parameter bytes; measured lookups are expected O(1) only under fixed addressing assumptions.

### 3.3 Geometry-constrained cross-state depth (mHC-inspired)
Form parallel fast, slow, relational and CED intermediate channels X_l. Optionally set nonnegative mixing B_l = Sinkhorn(exp(A_l)) with rows and columns summing to one (finite iteration has tolerances), and a residual-style depth map
  X_{l+1} = B_l X_l + G_l(X_l, retrieved_evidence).
Investigate spectral/nonexpansive bounds for B_l alone and separately Lipschitz/gradient bounds for G_l, the complete layer, and repeated depth; one doubly stochastic matrix is NOT an overall model stability proof. Allow learned latent geometry: regularized distance/angles between entity/world/event concepts, identity-respecting transformations, temporal continuity and counterfactual **predictive damage**. Test against matched unstructured and residual baselines; do not force geometric representations unless real data require them. B_l may depend on current causal state in a postscan layer, not the scan's precomputed P_t,Q_t.

### 3.4 Asymmetric CED concept-swarm refinement and compressed retrieval
Preserve original PR331 hypothesis: six 16D concepts, K=4 shared-weight message-passing iterations, coarse-to-fine readout. They are **proposed candidate dimensions** and must be brought under 95k–105k real active-param budget (<=1% matched comparator mismatch); old PR331's 32,701 vs 25,184 example is NOT parity-compliant. Define C_t^0=Proj(Z_t,Read(M_t),L_t), C_t^{k+1}=Phi_theta(C_t^k,C_t^0,selective_context_t) for k<4, final y_t=Head(C_t^4).
The four passes are sequential in **depth**, independent and vectorizable across available causal sequence positions, not O(1) serial depth and not infinitely recurring thought. Streaming performs four iterations per event. CED read-only future/action queries cannot mutate observed memory. Add optional sparse memory selection/CSA-like probes only if memory history is actually stored with documented capacity (a fixed 8x8 state is not a latent tape with 1M tokens). A causal prefix cache projected once from Z_t may serve CED when online; measured external/global caches add bytes and could break fixed-state claims. Include no-CED, K=1, K=4, equal-parameter deeper feed-forward and recurrent/nonparallel controls.

### 3.5 Triggered bounded replay and optional conditional expert/optimizer paths
Use a source-observable surprise/risk indicator to trigger a ring-buffer re-evaluation of the **last <=32 actually stored original observations**. Never use true future hazard labels as the trigger. Replay recomputes from a versioned checkpoint of the beginning of the buffer; replaying from current already-updated M would double-write. Define exact chronological replay equivalence for unchanged parameters/inputs and audit nonrepeatable masks, out-of-order events and timestamps. Replay is bounded by W=32 chronological operations and breaks unconditional O(1) worst-case inference time; quantify activation rate, worst-case latency and state+buffer bytes. A 608-byte dynamic state is preserved for the primary core ONLY, not the entire device state with concepts, ring buffer, codebook or KV.

Optional MoE routing, Muon/AdamW optimizer comparison and mHC depth go AFTER primary selective-memory headroom. Active and total parameters, optimizer state, training FLOPs, and token/actor budget are separately audited. Muon optimization is a candidate optimizer choice, NOT an architectural improvement credited to DeepSeek without matched optimizer controls.

## 5. Falsifiable acceptance and failure conditions

The candidate qualifies only if (A) original source/provenance and policy gates pass, (B) end-to-end source-to-output graph correctness and replay pass, (C) long+selective memory improves independently real future-state prediction on preregistered cases that actually require past evidence, against strongest matched neural/structured/physical baselines, (D) stationary no-regression and properly-scored uncertainty are satisfied, and (E) the measured memory/latency budget is met **including auxiliary stores**. If the best qualified baseline is stronger, preserve the negative and prioritize hypothesis correction rather than more rewrites. Claims of novel concept intelligence, CED causal reasoning, DeepSeek performance or autonomous hazard prevention remain PROPOSALS until separately empirically demonstrated.
